`flow.yaml` — контракт пакета процесса доставки. Schema version 1 описывает
метаданные, совместимость, узлы, переходы, входы, выходы, gates и ограниченную
доработку.

## Форма

```yaml
schemaVersion: 1
name: Feature delivery
compat:
  engine_min: 3.0.0
nodes:
  - id: implement
    type: ai_coding
    action:
      prompt: "Implement the task: {{ task.prompt }}"
    transitions:
      success: verify
  - id: verify
    type: check
    action:
      command: git diff --check
    transitions:
      success: review
      failure: review
  - id: review
    type: human
    finish:
      human:
        decisions: [approve, rework]
    transitions:
      approve: done
      rework: implement
    rework:
      allowedTargets: [implement]
      workspacePolicies: [keep]
      maxLoops: 3
      commentsVar: review_comments
```

Исполнение начинается с первого узла. `done` — зарезервированная цель
перехода, а не тип узла. Пример использует разрешённый раннер по умолчанию и
только проверку пробельных ошибок. Перед применением для поставки добавьте
реальные тесты проекта и обязательные доказательства. Неуспешную проверку
изучает человек перед решением о доработке.

Текущая версия движка — **3.8.0**. Указывайте минимальную версию, достаточную
для контрактов Flow. Если Flow полагается на подстановку контекста прогона
в промпт черновика консенсуса до запуска участников, задайте
`engine_min: 3.8.0`. Вывод участников вставляется в запросы проверяющих и
синтезатора как данные; похожий на шаблон текст в нём повторно не раскрывается.

## Правила автора

- Давайте каждому узлу стабильный уникальный id.
- Объявляйте все цели переходов.
- Ограничивайте каждый цикл доработки.
- Выбирайте runner явно или осознанно наследуйте его.
- Объявляйте обязательные входы и доказательства вне текста промпта.
- Используйте setup-скрипты только в доверенных исполняемых пакетах.
- Повышайте `compat.engine_min` только при необходимости нового контракта.

## Контракт установки

До запуска MAIster проверяет граф и совместимость. Ревизия и статус доверия
записываются при установке. Изменение источника не меняет активный прогон.
