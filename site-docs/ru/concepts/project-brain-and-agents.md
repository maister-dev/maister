Project Brain — управляемый слой знаний MAIster. Platform agents — именованные
работники из пакетов, которые могут использовать эти знания вне delivery Flow.
Вместе они позволяют проекту учиться, не превращая локальные заметки и фоновую
автоматизацию в невидимое состояние.

## Что хранит Project Brain

Project Brain разделяет курируемые источники проекта и память агента:

- managed references, правила проекта, заметки о зависимостях и документацию Flow;
- принятые уроки с источником, состоянием review и сигналами актуальности;
- предложения, которые человек может принять, отклонить или уточнить;
- приватную durable memory агента, подключённого к проекту.

Агент получает только разрешённый для запуска контекст. Сохранённое наблюдение
не становится правилом автоматически: сначала оно проходит proposal и review.

## Platform agents

У platform agent есть ревизия пакета, capability profile, доступы к проектам,
бюджет и политика триггеров. Его можно запустить вручную, по расписанию,
webhook, domain event или явному mention. Запуск появляется в том же ledger и
attention-поверхностях, что и другая работа MAIster.

Используйте platform agents для ограниченных процедур: triage, слежения за
зависимостями, review документации или поддержки знаний. Используйте Flow,
когда работа относится к delivery-процессу с gates и promotion.

## Агенты во встроенном Core package

MAIster Core содержит рабочие примеры контракта platform agents:

| Agent | Trigger | Ответственность |
| --- | --- | --- |
| `core:triager` | Task domain events или manual | Выбирает Flow, runner, ветку, priority, зависимости, дубликаты, clarification и enqueue intent. Он не обходит стандартный admission gate. |
| `core:improver` | Schedule или manual | Находит повторяющиеся кластеры evidence в Project Brain и создаёт небольшие proposals для human review. Сам их не применяет. |
| `core:experiment-judge` | Evaluation Lab | Оценивает скрытые Run-кандидаты по версионированной rubric. Он только советует и не может заключить Study или продвинуть победителя. |

Доверенные пакеты могут поставлять дополнительных агентов через ту же модель
identity, capabilities, triggers, policy, budget и project attachment.

## Операционное правило

Считайте обновления Brain и выход агента управляемыми артефактами. Проверяйте
durable knowledge, сужайте триггеры и просматривайте run и бюджет до разрешения
создавать последующую работу.
