ACP-раннер — профиль запуска кодирующего агента на конкретном узле. В нём
задаются адаптер, модель, маршрут к провайдеру, ссылки на переменные окружения и
политика разрешений. Проекты и Flow выбирают такие профили, а не произвольные
команды запуска.

## Что потребуется

- Глобальная роль администратора.
- Установленное приложение кодирующего агента на узле исполнения.
- Настроенная штатная авторизация приложения либо секреты провайдера в окружении
  процесса супервизора.

## Поддерживаемые семейства

Claude, Codex, Gemini, OpenCode и MiMo находятся в одном каталоге. Маршруты
провайдеров включают Anthropic, OpenAI, Google, собственные маршруты агента и
совместимые точки, включая OpenRouter. У каждого профиля отдельный результат
проверки готовности.

| Поле | Значение |
| --- | --- |
| Идентификатор | Устойчивая ссылка для проекта и слота Flow. |
| Адаптер | Консольный агент, запускаемый супервизором через ACP. |
| Модель | Модель, которую запрашивает адаптер. |
| Провайдер | Штатный или совместимый маршрут, адрес и параметры протокола. |
| Окружение | Значения или ссылки `env:NAME`, передаваемые процессу агента. Для секретов используйте ссылки. |
| Разрешения | Обычный интерактивный режим либо поддерживаемый адаптером режим без участия человека. |
| Включён | Может ли профиль участвовать в новых запусках. |
| По умолчанию | Общая запасная привязка, если проект или слот не выбрал другой совместимый раннер. |

## Создание раннера

1. Откройте **Настройки → ACP-раннеры**.
2. Добавьте профиль и выберите адаптер.
3. Укажите модель и маршрут провайдера.
4. Секрет положите в окружение супервизора, а в поле раннера укажите
   `env:NAME`.
5. Оставьте профиль выключенным до появления диагностики.
6. Включите его после состояния **Готов**.
7. Назначайте общим раннером по умолчанию только безопасный профиль для обычной
   работы.

Штатная авторизация консольных приложений сохраняется. Раннер может использовать
уже выполненный вход Codex, Claude Code или Gemini CLI без копирования ключа в
MAIster. Для каждого адаптера супервизор сохраняет положенное ему домашнее
окружение и файлы авторизации.

## Проверка готовности

Профиль недоступен, если не найден исполняемый файл, неверен его путь, провайдер
не поддерживается, отсутствует переменная окружения или не прошла инициализация
ACP.

Обычная готовность и готовность к сессии только для чтения проверяются отдельно.
Агент с рабочей областью `none` или `repo_read` требует поддержки такого режима
и, для соответствующих адаптеров, свежего результата специальной проверки.

## ACP как двусторонний канал

Супервизор не просто запускает терминальную команду. Через ACP он:

- переносит вопрос о разрешении человеку без принудительного режима YOLO;
- возвращает выбранный ответ в живую сессию;
- приостанавливает или останавливает работу;
- отправляет корректирующий запрос и возобновляет поддерживаемую сессию;
- передаёт ход исполнения на страницу прогона.

Так сохраняются привычные возможности настольных и консольных приложений
агентов, но с общей задачей и журналом решений.

## Привязка к этапам Flow

Flow может объявить именованные сессии и слоты раннеров. Проект разрешает каждый
слот при подключении либо первом запуске, а прогон сохраняет снимок выбора.

Узлы могут делить одну сессию или использовать разные. Поэтому планирование,
разработка и проверка могут выполняться разными кодирующими агентами и моделями
разной цены и уровня. Команда задаёт правило один раз и не перекладывает ручное
переключение на участников.

Проверяйте экономику в [Обсерватории](/ru/operations/costs-and-budgets), а
качество — в [исследовании сравнения](/ru/evaluation/run-comparison).

## Признаки ошибки

- `EXECUTOR_UNAVAILABLE`: нет включённого готового профиля нужного семейства или
  доказательства режима только для чтения.
- Неоднозначность: найдено несколько точных профилей, требуется явная привязка.
- Предупреждение о замене намерения: совместимый раннер найден, но модель или
  провайдер отличаются от запроса Flow.

Исправляйте указанную диагностику: установку, авторизацию, переменную окружения,
маршрут провайдера или привязку слота.
