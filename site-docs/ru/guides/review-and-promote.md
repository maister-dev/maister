description: "Проверьте изменения и доказательства, запросите доработку и продвиньте результат через PR или локальное слияние."
---

## 1. Проверьте цель

Сверьте проект, задачу, ревизию Flow, базовую и целевую ветки. Если база
изменилась, обновите прогон по подсказке интерфейса до оценки старых
доказательств.

## 2. Изучите результат

Прочитайте сводку и полный diff. Затем проверьте обязательные доказательства,
логи, структурированные результаты, решения людей и историю попыток. Зелёного
агентного узла недостаточно при отсутствующих или устаревших доказательствах.

## 3. Примите решение

- **Принять**, если результат и доказательства актуальны.
- **Вернуть на доработку** с конкретными комментариями.
- **Перехватить**, если работу должен продолжить человек.
- **Остановить**, если задача не должна продолжаться.

## 4. Продвиньте результат

| Режим | Результат | Требование к хосту |
| --- | --- | --- |
| `pull_request` | Публикует ветку и открывает pull request. | Авторизация провайдера и данные для git push |
| `local_merge` | Сливает результат в выбранную локальную ветку. | Чистый репозиторий и отсутствие конфликтов |

MAIster не развёртывает слитый результат. Deployment остаётся в существующем
CI/CD.

## Конфликты

При конфликте MAIster останавливает продвижение. Разрешите конфликт в
контролируемой рабочей копии, заново выполните затронутые проверки и проведите
review новых доказательств.
