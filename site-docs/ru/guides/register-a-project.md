---
title: "Подключить проект"
description: "Подключите локальный или удалённый git-репозиторий к MAIster без публикации его учётных данных."
---

## Условия

- Доступ администратора MAIster
- Git-репозиторий, доступный с хоста MAIster
- Чистая ветка по умолчанию
- Хостовые данные доступа для clone или fetch

## Существующая директория

1. Откройте **Проекты → Добавить проект**.
2. Выберите режим существующей директории.
3. Укажите абсолютный путь к репозиторию.
4. При необходимости задайте отображаемое имя.
5. Отправьте форму и проверьте результаты валидации.

Если `maister.yaml` отсутствует, MAIster проверяет настройки по умолчанию
в памяти и регистрирует runtime-конфигурацию без создания файла. Checkout
остаётся чистым. Для отдельного проверенного коммита используйте
[сохранение конфигурации в Git](/ru/guides/save-project-configuration).
Существующий невалидный файл вызывает ошибку конфигурации и не изменяется.

## Удалённый репозиторий

Выберите поддерживаемый режим clone и укажите URL. Используйте SSH-настройку
хоста, credential helper, авторизованный CLI провайдера или одноразовое поле
учётных данных в интерфейсе. Эти данные не записываются в `maister.yaml`.

## Валидация

MAIster проверяет идентичность и уникальность пути, slug проекта, структуру
манифеста, привязки Flow и ссылки на исполнителей. Исправьте каждую ошибку перед
повтором: платформа не подменяет репозиторий, Flow или runner молча.

## Результат

После регистрации откроется новый проект. Если репозиторию нужен первый
коммит или подключение удалённого репозитория, на доске появится подсказка.
Откройте **Зависимости проекта**, чтобы увидеть пакеты, отдельные Flow и
импорты возможностей. Они устанавливаются независимо после регистрации.
У недоступной зависимости останутся запрошенная версия и этап сбоя. Проектом
можно пользоваться, пока устанавливаются остальные зависимости.

Администратор платформы может повторить установку или изменить источник,
версию и подкаталог пакета. Сохранение версии запускает новую попытку.
Кнопка **Зарегистрировать ещё** открывает форму следующего проекта.
