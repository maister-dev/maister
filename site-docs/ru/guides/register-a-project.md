---
title: "Подключить проект"
description: "Подключите локальный или удалённый git-репозиторий к MAIster без публикации его учётных данных."
---

## Условия

- Доступ администратора MAIster
- Git-репозиторий, доступный с хоста MAIster
- Чистая ветка по умолчанию
- Хостовые данные доступа для clone или fetch

## Существующая директория

1. Откройте **Проекты → Добавить проект**.
2. Выберите режим существующей директории.
3. Укажите абсолютный путь к репозиторию.
4. При необходимости задайте отображаемое имя.
5. Отправьте форму и проверьте результаты валидации.

Если `maister.yaml` отсутствует, MAIster создаёт минимальный валидный манифест
с обнаруженной веткой по умолчанию. Существующий невалидный файл вызывает
ошибку конфигурации и не изменяется.

## Удалённый репозиторий

Выберите поддерживаемый режим clone и укажите URL. Используйте SSH-настройку
хоста, credential helper, авторизованный CLI провайдера или одноразовое поле
учётных данных в интерфейсе. Эти данные не записываются в `maister.yaml`.

## Валидация

MAIster проверяет идентичность и уникальность пути, slug проекта, структуру
манифеста, привязки Flow и ссылки на исполнителей. Исправьте каждую ошибку перед
повтором: платформа не подменяет репозиторий, Flow или runner молча.

## Результат

Проект появляется в портфеле и списке проектов. На его доске можно создать
задачу или запустить scratch-сессию.
