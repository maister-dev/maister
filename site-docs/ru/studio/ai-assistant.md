Помощник Flow Studio работает в редактируемом локальном пакете. Он объясняет
выбранный Flow, читает связанные файлы пакета и предлагает проверяемые
изменения.

## Как открыть помощника

![ИИ-помощник рядом с редактором Flow](/assets/screens/ru/flow-assistant.png)

1. Откройте **Flow Studio → Локальные пакеты**. Создайте пакет или нажмите
   **Создать ответвление** у установленного пакета.
2. Откройте файл `flows/<flow-id>/flow.yaml`. На главной странице пакета и в
   неизменяемой установленной версии кнопки помощника нет.
3. Дождитесь, пока редактор получит блокировку пакета.
4. Нажмите кнопку **ИИ** с иконкой искр в верхней панели. Вместо свойств узла
   справа откроется диалог. Повторное нажатие или крестик вернёт свойства.
5. Выберите готовый ACP-раннер, напишите один конкретный запрос и запустите ход.

При сворачивании панель остаётся подключённой. Можно открыть свойства узла и
вернуться к продолжающемуся диалогу.

## Какие данные получает помощник

MAIster собирает на сервере состав пакета, контрольные суммы файлов, граф Flow
и текущий фокус редактора. Перед ходом несохранённый буфер записывается в
черновик. ACP-сессия читает пакет через ограниченную рабочую область.

Для изменения помощник возвращает структурированное действие с путями,
исходными контрольными суммами и новым содержимым. MAIster проверяет блокировку,
пути, суммы, YAML, заголовки файлов, схемы и собранный граф. Только после этого
все файлы записываются одной операцией.

Пока помощник работает, редактирование человеком блокируется. Два автора не
смогут одновременно изменить черновик. Если контрольная сумма устарела,
действие отклоняется, а более новая правка человека сохраняется.

## Примеры запросов

- «Добавь узел проверки после `verify`, а доработку направь в `implement`».
- «Создай схему структурного результата для плана и передай результат в
  следующий узел».
- «Объясни ошибку проверки Flow, не меняя файлы».
- «Назначь дешёвый раннер на реализацию, а сильную модель оставь для плана и
  оценки».

После каждого изменения проверьте граф и разницу, затем нажмите **Создать
коммит**. Помощник сам не создаёт коммит и не выпускает срез.

## Если помощник недоступен

| Признак | Что проверить |
| --- | --- |
| Нет кнопки ИИ | Открыт ли файл Flow внутри локального пакета. |
| Нет раннеров | Настроен и проверен ли ACP-раннер в общих настройках. |
| Запуск недоступен | Есть ли текст запроса и принадлежит ли блокировка пакета вашему редактору. |
| Действие устарело | Обновите состояние пакета и повторите запрос с новыми контрольными суммами. |
| Ошибка проверки | Исправьте названный файл, схему, ссылку или граф. Частичных изменений в пакете нет. |
