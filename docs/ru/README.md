# MAIster: документация на русском

Эта папка — русская точка входа для людей, которые хотят понять MAIster как
инструмент: зачем он нужен, какие задачи закрывает и как через него вести
работу с AI-агентами. Английская документация в `docs/` остаётся канонической
для архитектуры, API-контрактов и деталей реализации.

## Для кого

- Технический основатель, CIO или staff engineer, который ведёт несколько
  репозиториев и хочет перестать управлять агентами через набор терминалов.
- Разработчик, которому нужно запускать AI-задачи воспроизводимо: с Flow,
  изолированной рабочей копией, human-in-the-loop и проверяемым diff.
- Оператор MAIster-инстанса, который отвечает за runners, проекты,
  доступы, бюджеты, HITL и безопасную доставку изменений.

## Как читать

1. Начните с [обзора](overview.md), чтобы понять назначение инструмента.
2. Перейдите к [первому запуску](getting-started.md), если нужно поднять
   проект локально.
3. Используйте [рабочий процесс](workflow.md) как ежедневную шпаргалку.
4. Возвращайтесь к [понятиям](concepts.md), когда встречаете термин вроде
   `Flow`, `HITL`, `run` или `workspace`.
