# Руководство пользователя MAIster

Единый иллюстрированный мануал: как вести работу с ИИ-агентами через MAIster
от регистрации проекта до слияния изменений. Собирается в один PDF.

Скриншоты сняты 2026-08-12 (светлая тема, русская локаль, 1440×900).
Интерфейс развивается; при расхождении верьте живому интерфейсу и снимите
скрины заново тем же маршрутом.

## Сборка PDF

```bash
./build.sh
```

Требуется pandoc 3.x и Google Chrome (другой Chromium-бинарь — через
`CHROME=/path/to/chrome ./build.sh`). Результат кладётся в
`build/maister-manual-ru.pdf`; каталог `build/` не коммитится (ADR-158).
