# Что такое MAIster

MAIster управляет работой ИИ-агентов над вашими приватными репозиториями.
Claude Code, Codex и другие ACP-совместимые агенты пишут код; MAIster
оборачивает их в управляемый процесс: проекты, доски задач, версионированные
Flow, изолированные рабочие копии, запросы к человеку (HITL), журнал событий,
просмотр изменений и контролируемое слияние в целевую ветку.

Вы видите, что делает агент, вмешиваетесь в нужный момент и принимаете
итоговый набор изменений по наблюдаемым данным, а не на веру.

## Какие боли закрывает

| Без MAIster | С MAIster |
| ----------- | --------- |
| Десяток терминалов, потерянный контекст | Портфель проектов, активные рабочие копии и единый инбокс |
| Прогоны не повторяются | Задачи запускаются через версионированные Flow-пакеты |
| Непонятно, что сделал агент | Прогон хранит логи, события, артефакты и изменения |
| Агент ждёт разрешения в терминале | HITL-запрос приходит в интерфейс, ответ уходит в живую сессию |
| Агент портит рабочую директорию | Каждый прогон работает в отдельном `git worktree` |
| Стоимость и автономность без контроля | Бюджеты, политики, гейты готовности, поток проверки |

## Основные экраны

| Экран | Для чего |
| ----- | -------- |
| Portfolio `/` | Обзор проектов и активных рабочих копий |
| Доска проекта `/projects/{slug}` | Backlog, задачи, запуск Flow, проектный инбокс |
| Прогоны `/runs`, `/runs/{id}` | История и детали прогонов |
| Scratch `/scratch-runs/{id}` | Свободная агентная сессия вне доски |
| Инбокс `/inbox` | Все ожидающие HITL-запросы и упоминания |
| Studio `/studio` | Flow-пакеты, источники, редактор Flow |
| Настройки `/settings` | Исполнители, MCP, системные настройки |

## Границы

MAIster не выполняет агентную работу сам. Агентные процессы живут снаружи:
`claude-agent-acp`, `codex-acp` и другие ACP-адаптеры. MAIster отвечает за
оболочку вокруг них: запуск, состояние, изоляцию, HITL, события и интеграцию
с git.
