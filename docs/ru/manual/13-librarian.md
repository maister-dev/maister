# Личный библиотекарь

Библиотекарь — один личный разговор для каждого пользователя MAIster. Откройте
его кнопкой в верхней панели. Разговор доступен с любой рабочей страницы;
закрытие панели не останавливает ответ или запущенную задачу. Значок сообщает
о новом ответе и решении, которое ждёт вас.

Опишите потребность обычными словами. Библиотекарь найдёт доступные вам
проекты и существующие задачи, предложит ответственную команду и формулировку
задачи. Перед созданием проверьте найденные дубликаты и явно назовите, какие
задачи принять. Создание задачи само по себе не запускает Flow.

Для каждой задачи можно отдельно выбрать дальнейший шаг:

| Действие | Что произойдёт |
| --- | --- |
| Создать и оставить | Задача останется в Backlog без намерения запуска. |
| Отправить в триаж | Триажер выберет маршрут. Режим «только триаж» не запускает Flow автоматически. |
| Запустить | MAIster применит обычные проверки доступа, готовности исполнителя, зависимостей и лимитов. В ответе будет ссылка на реальный прогон и его состояние. |
| Уточнить у коллеги | Адресный вопрос появится у участника проекта и в задаче. Блокирующий вопрос удержит запуск до ответа или отмены. |

Ответ коллеги приходит в личный разговор как обновление со ссылкой на задачу.
Он остаётся данными для обсуждения: не меняет принятую формулировку и не
разрешает запуск сам по себе. Карточку подтверждения проверяйте перед нажатием:
она привязана к конкретной задаче или прогону и его текущей версии. Если
объект изменился, подтверждение будет отклонено.

## Контекст и память

- **Остановить ответ** прерывает только текущий ответ библиотекаря. Для
  остановки прогона используйте отдельное действие на прогоне.
- **Сбросить контекст** начинает новую тему в том же разговоре. Прежняя
  переписка остаётся в истории, а задачи, явная личная память и открытые
  вопросы коллегам сохраняются. Непринятые карточки прежней темы очищаются.
- **Память** содержит личные предпочтения, цели, обязательства и факты. Запись
  можно изменить или забыть. Забытое не возвращается автоматически из старой
  сводки; снова запомнить его можно только явным действием.
- **Удалить историю** сначала показывает состав удаления, затем удаляет личные
  сообщения и их сводки. Принятые формулировки задач, опубликованные цитаты и
  журнал действий сохраняются. Ссылка на удалённое исходное сообщение будет
  честно помечена как недоступная.

Личная память библиотекаря отделена от «Мозга проекта». Информация проекта
доступна библиотекарю только пока у вас есть доступ к этому проекту. Слияние
изменений означает слияние, а не развёртывание или приёмку результата.

Для владельца инстанса: библиотекарь включается в настройках ACP-исполнителей.
Нужен готовый исполнитель Claude. Лимиты и сроки хранения задаются в
окружении веб-процесса; см. [Configuration](../../configuration.md#personal-librarian--platform_runtime_settings-implemented--adr-185).
Codex пока недоступен для библиотекаря: встроенное чтение файлов хоста не
имеет проверенного механизма запрета.
