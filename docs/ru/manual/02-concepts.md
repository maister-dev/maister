# Ключевые понятия

Короткий словарь, чтобы читать интерфейс и остальные главы без погружения в
код. Подробная версия — в [Ключевых понятиях](../concepts.md).

- **Project** — зарегистрированный внешний git-репозиторий со своей доской
  задач, Flow-пакетами и исполнителями. Один `repo_path` — один Project.
- **Flow** — воспроизводимый сценарий доставки: граф типизированных узлов
  (агентная работа, проверки, формы, проверка человеком), какие шаги
  выполнить и где нужен человек.
- **Package** — поставка нескольких Flow, навыков и агентов из git-источника.
  Устанавливается по тегу, версии неизменяемы; проект подключает пакет и
  получает его Flow на доске.
- **Task** — работа в бэклоге проекта: запрос + выбранный Flow. Одну задачу
  можно запускать повторно, получая новые попытки.
- **Run (прогон)** — конкретная попытка выполнить задачу или scratch-сессию.
  Хранит статус, снимок исполнителя, рабочую копию, события, HITL,
  доказательства и итоговые изменения. Статусы — в главе
  «Задачи, запуск и прогоны».
- **Workspace (рабочая копия)** — изолированный `git worktree` конкретного
  прогона. Агент не трогает основную директорию репозитория.
- **Supervisor** — отдельный процесс-демон, который владеет ACP-сессиями,
  запускает адаптеры агентов, следит за живостью и публикует события.
  Веб-интерфейс не запускает агентов напрямую.
- **ACP** — Agent Client Protocol, стандартная граница между MAIster и
  реальным агентом разработки. Благодаря ACP поддерживаются разные адаптеры:
  `claude`, `codex`, `gemini`, `opencode`, `mimo`.
- **Runner (исполнитель)** — настроенный способ запустить агента: адаптер,
  модель, провайдер, политика разрешений, готовность.
- **HITL** — момент, когда Flow или агент ждёт человека: разрешение, форма,
  комментарии к доработке или ручной перехват.
- **Evidence (доказательства)** — проверяемые артефакты результата:
  изменения, логи, проверки, вывод узлов, сводка готовности. Итог принимают
  по наблюдаемым данным, а не на веру.
- **Платформенный агент** — служебный агент вне доски задач (триаж,
  регулярные проверки, судейство), поставляется внутри пакетов и запускается
  по триггерам. Глава «Платформенные агенты».
- **Мозг проекта** — долговременная память проекта: заметки, индекс кода и
  документации, предложения новых записей из прогонов. Глава «Мозг проекта».
