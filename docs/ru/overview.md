# Обзор

MAIster — self-hosted execution and governance layer для воспроизводимых
AI-powered SDLC-процессов над приватным кодом. Claude Code, Codex и
другие агенты выполняют работу. MAIster добавляет проекты, доски задач,
запускаемые Flow, изолированные рабочие копии, HITL, журнал событий, просмотр
изменений и безопасное продвижение в целевую ветку.

## Зачем нужен инструмент

Когда ИИ-агенты запускаются вручную, рабочий процесс быстро распадается:

| Боль | Что делает MAIster |
| ---- | ------------------ |
| Много терминалов и потерянный контекст | Показывает портфель проектов, активные рабочие копии и единый ящик входящих запросов |
| Неповторяемые прогоны | Запускает задачи через версионированные Flow-пакеты |
| Непонятно, что сделал агент | Сохраняет прогон, логи, события, артефакты, доказательства и изменения |
| Агенту нужно разрешение | Выводит HITL-запросы в интерфейс и возвращает ответ в живую ACP-сессию |
| Риск испортить рабочую копию | Создаёт отдельный `git worktree` на прогон |
| Нужно несколько агентов | Поддерживает ACP-исполнителей: `claude`, `codex` и адаптеры с проверкой готовности |
| Нужно контролировать стоимость и автономность | Использует бюджеты, политики, гейты готовности и поток проверки |

Главная идея: агент делает работу не в “чёрном ящике”, а внутри управляемого
процесса, где человек видит состояние, может вмешаться и принимает итоговый
набор изменений перед слиянием.

Часть адаптеров, включая Gemini, OpenCode и MiMo, нельзя считать готовыми
только потому, что они добавлены в каталог: их запуск проходит через проверки
готовности и сохранённые данные ACP smoke test.

## Что можно делать в MAIster

- Зарегистрировать несколько проектов и видеть их в одном портфеле.
- Создать задачу в бэклоге проекта и запустить её через выбранный Flow.
- Запустить scratch-сессию для свободной работы агента вне задачи на доске.
- Ответить на HITL-запрос: разрешение, форма, комментарии для доработки.
- Открыть прогон, посмотреть ход выполнения, рабочую копию, доказательства,
  шкалу событий и изменения.
- Принять работу: локальное слияние или продвижение через PR, если настроен провайдер.
- Управлять исполнителями, Flow-пакетами, MCP, агентами и настройками инстанса.

## Где границы

MAIster — это не новая среда выполнения агентов. Агентные процессы живут снаружи:
`claude-agent-acp`, `codex-acp` и другие ACP-адаптеры выполняют работу.
MAIster отвечает за оболочку вокруг них: запуск, состояние, доступы,
изоляцию, интерфейс, события, HITL и интеграцию с git.

## Основные экраны

| Экран | Для чего нужен |
| ----- | -------------- |
| Portfolio `/` | Обзор проектов и активных рабочих копий |
| Project board `/projects/{slug}` | Backlog, задачи, запуск Flow, проектный ящик входящих запросов |
| Runs `/runs` и `/runs/{id}` | История и детали прогонов |
| Scratch run `/scratch-runs/{id}` | Свободная агентная сессия |
| Inbox `/inbox` | Все ожидающие HITL-запросы и упоминания |
| Studio `/studio` | Flow-пакеты, локальные пакеты, редактор Flow |
| Settings `/settings` | ACP-исполнители, Brain, webhooks, системные настройки |
