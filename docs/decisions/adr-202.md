# ADR-202: Company ownership and evidence-linked knowledge revisions

[Back to ADR index](../decisions.md#adr-202-company-ownership-and-evidence-linked-knowledge-revisions)

**Date:** 2026-11-02
**Status:** Accepted

**Context:** Project Brain records, indexing and improvement proposals already exist. They are project-bound; retrieval scores and source anchors do not establish factual confirmation or immutable historical evidence. Company knowledge needs an owner without a repository and access narrower than company membership.

**Decision:** Extend native Brain with company-or-project ownership, explicit access grants, immutable current-record revisions and source witnesses. Keep the existing item identity and retrieval projection. Separate publication, assertion basis, confirmation, freshness, evidence availability and retrieval ranking. Confirmation is an attributable policy decision over an exact record revision and evidence set. Preserve contradictory claims; automatic similarity supersession cannot adjudicate them. Private agent and librarian memory remain separate stores.

The contract is **Designed**. [Company Brain](../system-analytics/company-brain.md) owns record and authority behavior; [evidence](../system-analytics/company-brain-evidence.md) owns source witnesses. Their implementation is not implied by this decision's acceptance.

**Consequences:** Main migrations establish company identity before Brain migrations reference it. Legacy records receive an explicitly imported current-state baseline without fabricated authorship, observation time, review or verification. New main migration SQL never depends on new Brain tables; service validation protects references after both lineages are provisioned. Accepted revisions and decisions are append-only, with explicit correction/supersession history.

**Alternatives Considered:** A dummy project couples company knowledge to a repository. A parallel vector/knowledge engine duplicates Brain. One status/confidence value conflates unrelated evidence and publication decisions. Semantic auto-merging cannot establish factual truth.
