# ADR-211: Reviewed installation agent reach

> Part of the ADR log — [index and editing rules](../decisions.md).

**Date:** 2026-11-19
**Status:** Accepted

**Context:** Company agent bindings already support repository-free execution. Installation-wide analysis needs a precise read boundary and durable source attribution.

**Decision:** The company binding has an explicit, reviewed `all_non_archived_projects` mode. Only a global administrator may create or widen it. Installation agents run with workspace none and a positive list of MCP operations. Manual runs intersect the frozen binding with current grant and initiating user rights. A reviewed cron or event runs as the bound agent under the grant. Installation sessions write through pending proposals. Record all disclosed project and finer-grained sources before returning private bytes.

**Consequences:** Older bindings remain company-only. The current binding revision, credential and source checks fence every operation. A reader needs permission to all sources of a retained revision.

**Alternatives Considered:** A second agent catalog would duplicate binding lifecycle and trust decisions. Ambient installation access would widen existing agents.

See the [specialist runtime contract](../system-analytics/specialist-runtime.md).
