# ADR-205: Stand operation intents and independent verification

[Back to ADR index](../decisions.md#adr-205-stand-operation-intents-and-independent-verification)

**Date:** 2026-11-02
**Status:** Accepted

**Context:** Operational runs already have frozen result/completion contracts and durable host commands. A restart is an external effect that may succeed after its response is lost. Run success, agent prose, HTTP/process success or current liveness does not establish the requested effect or post-action health.

**Decision:** Use a narrow configured first-party stand helper, supervisor-owned transport, platform and target durable operation identity/intent, canonical service-resource exclusion, current pre-effect authority and separately issued verification. Keep effect, verification and reconciliation disposition independent. A lost response queries the same operation/target journal before an original mutation retry. Unknown effects remain unknown; an authorized inspected successor has a new identity and explicitly linked prior uncertainty. Reconciliation survives run/host-assignment termination under its own current recovery grant and fence.

The contract is **Designed**. [Stand maintenance](../system-analytics/stand-maintenance.md) owns operation state, authority, verification, recovery and qualification.

**Consequences:** The first connector supports configured Linux systemd scope/user/unit actions only. No generic shell or controller self-update. Diagnosis/restart/independent verification is qualified before configuration/upgrades. Target receipt durability and bounded sanitized logs are required deployment properties. Existing scheduler, run/attempt/result ledgers, HITL, incidents and outbox remain authoritative in their domains.

**Alternatives Considered:** Blind HTTP retry risks repeated effects. An expiring mutex alone loses unknown effects. Treating health as proof of restart invents causal evidence. Extending the supervisor command ledger into a generic business-operation store conflates different owners/lifetimes.
