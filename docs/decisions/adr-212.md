# ADR-212: Unified optional knowledge and memory review

> Part of the ADR log — [index and editing rules](../decisions.md). Amends [ADR-169](adr-169.md) and [ADR-171](adr-171.md).

**Date:** 2026-11-19
**Status:** Accepted

**Context:** Several governed proposal queues expose separate decision controls. This work can be reviewed centrally without changing what counts as blocked work.

**Decision:** Use one reviewer-filtered Inbox projection for vault, Project Brain and native knowledge decisions. Use their existing domain decisions with an explicit receipt for each batch item. Add the neutral reviews count and its opaque visible-state version to the existing attention stream.

**Consequences:** Existing proposal screens lead to filtered Inbox review and retain read views. A skip, revocation or hidden row cannot expose the proposal or affect the visible count. Amber decisions and Activity updates retain their existing sources.

**Alternatives Considered:** Counting optional proposals as decisions would change the semantics of the amber badge. Separate review buttons and streams would add duplicate action and invalidation paths.

The [attention contract](../system-analytics/attention.md) owns the Designed review projection.
