# ADR-218: Recoverable installation of project dependencies

**Status:** Accepted
**Date:** 2026-11-23

**Context:** An unavailable package member can undo a successful repository clone under the registration policy of ADR-088 and ADR-131.

**Decision:** Commit repository identity, owner, validated configuration and desired dependencies before installing external content. Record independent outcomes for packages, standalone Flows and capability imports. The registration UI opens the accepted project by its returned slug. This revises the registration destination in ADR-172 D3. Operators may correct package coordinates in project settings and explicitly save them through the reviewed Git workflow.

**Consequences:** A registered project may have pending or failed dependencies. Runtime admission still requires an eligible effective revision. A failed or uncertain attempt remains available for diagnosis and fenced recovery.
