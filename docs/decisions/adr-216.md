# ADR-216: Evidence-gated autonomous completion

> Part of the ADR log. See the [index and editing rules](../decisions.md).

**Date:** 2026-11-20
**Status:** Proposed

**Context:** The existing delivery lanes can publish a branch or merge
selected categories. A reviewed Flow can also supply CI and review evidence
strong enough to authorize some code changes and confirm delivery.

**Decision:** Add the default-off `autonomousCompletion` execution policy
axis. A reviewed pinned manifest and launch grant identify eligible actions
and required attestations. A live platform stop, project policy and run hold
can narrow the launch authority. Bind readiness, CI, review and diff limits
to the same tested source HEAD, reviewed base and publication generation.
Use the current promotion claim for delivery. Verify exact merge evidence
before a system actor finalizes a PR-backed run. A permitted graph failure
edge can classify timeout or exhaustion. Record decision, effect and outcome
at their owning transaction boundaries.

**Consequences:** Unqualified or held decisions retain Review with their
reason. Operators retain the existing recovery and finalize operations.
A verified human reversal refers to the exact completed delivery. Queueing,
conflict resolution and new evidence acquisition retain normal run admission.

**Alternatives considered:** Treat CI success or PR creation as completion.
Neither attests the required review, authority and delivered Git state.
