# ADR-223: Prepare package MCPs on the assigned supervisor

> Part of the [ADR log](../decisions.md).

**Date:** 2026-11-24
**Status:** Implemented

**Context:** Studio adds declarative MCP servers that can be selected independently for agent sessions. The supervisor owning the workspace can differ from the Web process and the default supervisor.

**Decision:** Use the selected-supervisor workspace ownership and host registry from [ADR-219](adr-219.md). Prepare reviewed npm distributions under the Run's active assignment and epoch. The assigned supervisor verifies its approval, archive digest and runtime before publication, resolves credentials locally and executes the selected workload. The facade uses that supervisor's configured Web origin and local executable.

**Consequences:** A newly assigned host prepares its own cache. Continuation still requires the original workspace and checkpoint. Earlier shared-workspace probes are retained in the branch plan as qualification for that historical build. See the [operator settings](../configuration.md#assigned-supervisor-mcps).
