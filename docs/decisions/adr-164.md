# ADR-164: Remove managed Claude Code Router support

> Part of the ADR log — hub, index, and editing rules: [`../decisions.md`](../decisions.md).

**Date:** 2026-09-02
**Status:** Implemented

**Context:** Anthropic-compatible routing is already expressible through typed
runner provider configuration and supervisor environment references. Keeping a
second, MAIster-managed Claude Code Router path adds a daemon lifecycle,
sidecar persistence, admin UI, API surface, diagnostics, and a separate model
catalog source without being required for the supported routing use cases.

**Decision:** Remove Claude Code Router as a MAIster component. The supervisor
does not bundle, start, stop, health-check, or inject configuration for CCR.
Platform runners have no sidecar reference. The web tier exposes no sidecar
CRUD or lifecycle UI/API. Anthropic-compatible providers use
`provider.kind: anthropic_compatible`, a typed `base_url`, and an `env:NAME`
credential reference resolved by the supervisor at launch.

The database migration drops `platform_acp_runners.sidecar_id` and
`platform_router_sidecars`. Historical runner snapshots may retain unknown JSON
keys, but new snapshots and public contracts omit them.

**Consequences:**

- One routing path remains: typed runner provider config plus environment refs.
- Supervisor lifecycle and diagnostics no longer include a router daemon.
- Existing sidecar rows and runner-sidecar bindings are removed by migration;
  operators must configure equivalent direct provider runners before upgrading
  if they still need those routes.
- The CCR-specific portions of ADR-005, ADR-050, ADR-076, ADR-094, and ADR-115
  are superseded; their non-CCR decisions remain in force.

**Alternatives Considered:**

- Keep CCR as an external-only sidecar: rejected because it preserves the
  sidecar schema, UI, and branching contracts while still duplicating direct
  provider configuration.
- Keep the dependency but hide the UI: rejected because the supervisor would
  still own unnecessary lifecycle and security-sensitive env injection.
