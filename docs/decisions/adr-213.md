# ADR-213: Librarian knowledge and vault confirmations

> Part of the ADR log — [index and editing rules](../decisions.md).

**Date:** 2026-11-19
**Status:** Accepted

**Context:** A librarian can convey owner-authorized knowledge and help prepare edits to memory without acquiring an agent's execution authority.

**Decision:** Allow named read operations under live turn-bound owner authorization. Use ADR-187 confirmation cards for governed knowledge, Brain and vault mutations. Freeze intended content, source constraints, target identity and preconditions. The owner confirm action reauthorizes and settles the effect, audit and receipt in one DB transaction.

**Consequences:** Existing domain rules determine whether the effect is a pending proposal or human edit. Librarian-created vault confirmations require human editing authority at decision time. Explain mode reads only. Summaries remain tool-less.

**Alternatives Considered:** Direct librarian mutation would bypass explicit owner confirmation. A synthetic agent credential would obscure attribution and target authority.

See the [librarian authority contract](../system-analytics/librarian-authority.md).
