# ADR-220: Flow node questions and checkpoint continuation

> Part of the [ADR log](../decisions.md).

**Date:** 2026-11-24
**Status:** Implemented

**Context.** A package agent in a Flow can need a human decision while other nodes remain runnable. The human response and the host's acceptance of the successor prompt are distinct events.

**Decision.** Persist the question against its exact Flow attempt, prompt ordinal, host assignment and incarnation. A successful checkpoint makes it visible to project responders through the Run and Inbox. The first authorized answer is immutable. Resume the original ACP session with a successor prompt and record delivery after the command ledger proves host acceptance. Project the delivery independently of the canonical command evidence and recover it from durable command and incarnation witnesses.

**Consequences.** Terminal Run transitions close outstanding questions and assignments. An unanswered question closes by supersession, so its response fields retain the unanswered shape. The private librarian retains its own conversation-bound question type. See [Human-in-the-loop](../system-analytics/hitl.md) for the response and withdrawal rules.

**Amendments.**

- 2026-11-26 — Terminal writers that own the Run transaction close undelivered node questions and their assignments in that transaction. A bounded recovery sweep settles retained questions from terminal Runs that bypassed the close. Terminal Run and attempt state immediately removes response authority. If a successor prompt already proves delivery, its independent projection can finish after Run settlement.
