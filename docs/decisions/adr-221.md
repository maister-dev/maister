# ADR-221: Reviewed public catalog imports and host-approved npm MCPs

> Part of the [ADR log](../decisions.md).

**Date:** 2026-11-26
**Status:** Implemented

**Context.** Package editors need to find skills and MCP servers and review
the version and companion files before adding them to a draft. A public
listing identifies a publisher and artifact. It grants no runtime authority.

**Decision.** Search configured public GitHub repositories and the official MCP
Registry. Treat skills.sh links as discovery into an approved repository.
Resolve the exact Git commit or versioned Registry record through bounded
HTTPS reads and verify Git file identity. Preview the pinned content and
notices, then apply it through the package edit lock and durable import
receipt. Preview and apply write declarative data. Keep credential values
outside packages and reject unsupported registry requirements with safe
configuration names when available.

**Consequences.** A public MCP import follows the project's current binding
and execution trust. The first supported stdio distribution is an exact,
self-contained npm release with reviewed integrity, publisher identity and
binary. The assigned supervisor independently checks its operator-approved
descriptor digest and verifies the archive and runtime before preparing a
host-local installation. Any new host needs its own approval, credentials
and compatible runtime. See [catalog authoring](../system-analytics/flow-studio.md#catalog-authoring),
[MCP placement](../system-analytics/execution-hosts.md#mcp-placement-implemented)
and the [external API references](../api/external/README.md).
