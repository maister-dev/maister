# ADR-219: Selected supervisor workspace ownership

> Part of the ADR log. See the [index and editing rules](../decisions.md).

**Date:** 2026-11-23
**Status:** Accepted

**Context:** The manager assigns ACP sessions to a supervisor, but normal
launches still create Git worktrees in Web before the Run and its execution
assignment are committed. Web also performs execution-side CLI and Git work.
Host selection requires both authority over the chosen physical workspace
and durable ownership before the first side effect.

**Decision:** Commit the authorized Run, addressed assignment, preparation
claim and stable command intent together before checkout. Verify the
selected supervisor identity and protocol before delivery. The supervisor
owns its Git cache, worktree generations, children and runtime output.
Postgres owns admission and projections. The host's private SQLite store
owns physical receipts and canonical events. After assignment release an
active workspace-operation claim fences mutation on the retained owner.
Recovery uses the original command and owner or starts a separately
authorized new attempt after quiescence is proved.

The compatibility issuer may create an assignment for a never-placed legacy
Run on the default supervisor. Addressed launch commits an assignment with
the workspace reservation. Any Run with prior placement must use the durable
owner and the applicable placement transition from ADR-166.

**Consequences:** Qualify one configured host before enabling two trusted
endpoints. Verify both placements locally with isolated stores, processes
and network endpoints on one development machine. Repeat the same workflow
on two physical machines to qualify trusted-network deployment. Preserve
historical local-path records through the
migration and quarantine ambiguous ownership. A compatible one-host
deployment can upgrade before enabling addressed dispatch. Developer
enrollment and Kubernetes workload execution have separate release gates. In G2,
stale heartbeat preserves physical ownership and claimed capacity until the
owning host proves quiescence for the exact epoch. The pilot uses no execution
lease or deadline takeover.

The supervisor listener requires an operator-controlled private network.
Its host key is public on the health endpoint and validates routing identity.
Web authenticates its users and authorizes project and Run operations before
calling the supervisor. Trusted developer enrollment belongs to Stage D.

**Alternatives considered:** Routing session creation by URL would leave
checkout and project checks on Web. A shared filesystem would couple
cache paths, writer exclusion and recovery to deployment topology.
