# ADR-204: Native evidence findings and governed reduction

[Back to ADR index](../decisions.md#adr-204-native-evidence-findings-and-governed-reduction)

**Date:** 2026-11-02
**Status:** Accepted

**Context:** RAH already supports pinned structured child results and direct-child collection. Its reference research/reduction payloads do not define evidence preservation. Models cannot be trusted to mint authorship, permissions, source versions or confirmation authority.

**Decision:** Add a native versioned `evidence_findings_v1` profile/export value using the existing bounded FormSchema/output/result ledger. Models supply assertions, candidate refs, basis, limitations, questions and proposed changes; the server validates referenced identities/current access/version witnesses and records attribution. Reducers account for consumed findings with a bounded selection manifest and retain the exact evidence closure of declared source findings. Direct-child collection stays intact; intermediate results carry original origins through depth 2. Server-recorded source restrictions propagate even when citations are omitted.

The contract is **Designed**. [Evidence findings](../system-analytics/evidence-findings.md) owns wire semantics, semantic-validation limits and depth-2 behavior.

**Consequences:** Missing evidence is a valid explicit outcome, never a reason to fabricate citations. Validated reference integrity is not proof of assertion truth, semantic entailment or independent corroboration. Novel inferred conclusions remain unconfirmed/reviewable. Existing profiles and operational_v1 snapshots stay unchanged; a new versioned operational evidence contract composes the native finding shape with server-verifiable operation/health refs.

**Alternatives Considered:** Prompt-only prose loses source identity. Collecting arbitrary grandchildren weakens existing authority. Requiring every child body copied into every reduction defeats bounded output. Model-declared provenance/classification cannot enforce access or factual confirmation.
