# ADR-222: Package capability delivery

> Part of the [ADR log](../decisions.md).

**Date:** 2026-11-24
**Status:** Accepted

**Context:** A project can attach both design and development packages. Preparing their pinned contents for a Flow Run currently also makes unrelated tools available to agents. Shared coding skills still need to be discoverable from both products.

**Decision:** Capture package revisions when admitting the Run. Resolve discovery and MCP delivery separately for each session from its owning Flow, bound agent profile, effective project scope and explicit instance additions. Prepare selected MCPs on the assigned execution host. Specified new releases default to sharing skills and to keeping each MCP local. A Flow ships its required skill dependencies.

**Consequences:** Project users can select work by Flow without choosing a capability profile. A versioned Run witness and current execution authority are both required on resumed dispatch. Adjacent bound agents require distinct sessions and adapter discovery views. See the [inventory decision table](../system-analytics/capabilities.md#project-run-capability-inventory).
