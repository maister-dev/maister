# Preserve Studio delivery across the Stage C rebase

**Date** 2026-11-26 21:01 MSK

**Severity** high

**Files** Studio catalog search, package delivery, Web execution-host and Flow question services, Supervisor session creation, migrations `0402–0409` and owning contracts.

## Problem

Studio and Stage C allocated overlapping ADRs and migrations. A required MCP
could disappear from an agent session after the final trust or transport check.
The host-owned preparation path could discover a same-named skill from the wrong
bundle or refuse a standalone launch when the project had other ready bundles.
Exact skills.sh links and update checks depended on search ranking. Flow
questions reopened database transactions while waiting for the prompt owner,
and the librarian transcript contract implied an answerable card before the
checkpoint. A slow catalog provider could hold back the entire result list.

## Root Cause

The branches evolved their host registry and numbered artifacts independently.
MCP admission and final dispatch filtered capabilities at different boundaries.
The addressed host had a sealed workspace manifest but no session-level witness
for the selected trees. Catalog discovery, item identity and reviewed content
had different sources of authority. Question creation had durable ownership
checks without a notification for their completion.

## Solution

Keep the master journal prefix and ADRs intact. The Studio command-kind migration
extends the Stage C set, and the librarian migration declares its composite
unique key before adding the dependent foreign key. Assert required MCPs after
the final filter. Addressed sessions verify selected skill digests against the
retained manifest and share that inventory between adapter and prompt. A
standalone launch captures its providing package through its verified root.
The Flow capture retains its project-bundle snapshot checks. Search
providers settle independently, and previews verify the chosen skill at a Git
commit. PostgreSQL wakes waiting Flow questions on the relevant committed state
changes. The service rechecks ownership on wake. A Librarian card opens after
checkpoint confirmation. Legacy import writes the consumer columns present in
its pre-0135 window. Migration 0376 backfills the horizon from the retained rows.

## Prevention

Use `rg -n 'assertRequiredMcpServers\(|addressedPackageSkills|waitForFlowQuestionPrompt\(' web/lib supervisor/src docs/api`
to audit the two MCP gates, Flow and standalone session writers, supervisor
schema and consumer, and question wait. Compare the full master journal prefix
and migration snapshot parents. Run a populated upgrade with a real reserved
Stage C workspace command. Seed historical fixtures with columns from their
actual cutoff. Keep replay receipts separate from artifacts in E2E
assertions. Artifact creation and database acknowledgement can settle at
different times. RED reproduced a missing required MCP, an accepted bad skill
digest, a standalone launch refused with another ready bundle, catalog identity
failures and repeated PostgreSQL reads. The focused
integration and production browser checks exercise those boundaries after the fix.
