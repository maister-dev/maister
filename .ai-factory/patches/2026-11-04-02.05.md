# Exercise agent fixtures through their actual admission and provenance contracts

**Date:** 2026-11-04 02:05
**Files:** web/lib/agents/**tests**/agent-flow-launch.integration.test.ts; web/lib/agents/**tests**/triggers.integration.test.ts; web/lib/agents/**tests**/triager-wire.integration.test.ts; web/lib/services/**tests**/agent-question.integration.test.ts
**Severity:** medium

## Problem

The complete integration run exposed agent fixtures that assumed a trigger
label authorized a task launch, a legacy triage verdict authorized automatic
delivery, or a comment observer could allocate ordinary delivery roots. They
also expected the old two-event clarification sequence and used public raw Run
allocation for scheduled-request successors.

## Root Cause

The fixtures crossed the new admission boundary without its actual authority
or frozen request. A manual trigger label is provenance, not an authenticated
human decision. Automatic delivery requires current accepted qualification even
for legacy tasks. Operational comment/context observers are a separate agent
kind with an operational completion contract; inferring that role from a
read-only workspace or a generic prompt leaves them ordinary delivery actors.

New authoritative checks also exposed incomplete fixture prerequisites:
package and same-package Flow revisions differed; operational packages lacked
the required engine compatibility declaration; an agent-authored event had no
producing Run and was correctly fenced by chain-depth validation; and a fake
repository path refused before the intended qualification check. Retained
Run/intent lineage cannot be removed by deleting either referenced table first.

## Solution

Task-bound manual fixtures obtain the server preview witness and an opaque
authenticated session principal, accept a canonical intent, then prepare that
intent. Scheduled source input comes from a real cron reservation. Manual
relaunch retains lineage through fresh admission; budget restart uses the real
preview and HITL decision, verifies its truthful pending receipt, then prepares
the successor. Its policy equals the displayed preview exactly; ordinary
manual relaunch still verifies the fresh supervised default. Session permission
checks use the actual persisted user and owned database; only the absent Next
request-lifecycle callback is adapted in this service-level fixture.

The legacy Triager wire test first proves that enqueue alone launches nothing,
then explicitly sends the task to triage and submits an assessment through the
real qualification service before the automatic tick may select its Flow. The
held case uses the real flag writer. This is controlled assessment input, not
evidence of a production model completing qualification.

Only the routing/context observers declare operational kind and completion;
the general seed default remains code delivery. Their new input events are
persisted with real generated IDs. An actual operational source Run supplies
the agent-authored comment's chain proof, and self-exclusion preserves exactly
that original Run. A separate delivery control uses a real Git repository and
asserts `qualification_required`, no Run and no intent, so comment actor metadata
cannot become human authorization. Ordinary delivery reservation coverage stays
in the authoritative admission suites.

Clarification coverage now checks the exact ordered qualification-change,
triage-requeue and clarification-answer events, including the authoritative
input-revision payload. Active fixture intents are cancelled through the real
service before the owned test database removes its retained project graph
atomically; no lineage or admission snapshots are rewritten to aid cleanup.

## Prevention

Classify fixture actors and source families before adapting failed counts.
Establish all earlier technical prerequisites so a negative test reaches the
specific guard it claims to cover. Preserve typed refusal reasons, real source
IDs, exact event sequences, original lineage and the user's displayed settings.
Use captured safe refusal diagnostics to distinguish fixture setup failures
from product defects rather than relaxing assertions.
