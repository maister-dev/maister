# Reconcile diagnostic prose with its authoritative producers

**Date:** 2026-11-06 22:19 (Europe/Moscow)
**Files:** `docs/system-analytics/execution-hosts.md`, `docs/screens/projects/project-agent-history.md`, `docs/architecture.md`
**Severity:** documentation correctness

## Root cause

A secondary host-state entity description retained schema version 14 after the
canonical host implementation and Supervisor guide advanced to version 16 and
added private session-process obligations. Separately, a screen description
carried the initial-preparation no-model explanation into every preparation
failure, including continuations with earlier model execution. The architecture
component map also retained a template-era eight-table count; it now links the
canonical schema and generated ERD instead of duplicating that changing count.

## Correction

Align the private-store entities and version with `HOST_STATE_SCHEMA_VERSION`
and the guarded upgrades in `supervisor/src/host-state.ts`. Preserve the boundary
that the Web tier never reads that private store.

Describe Run preparation failures as infrastructure incidents with neutral
wording about historical model execution. Permit the no-model explanation only
for the current task-input failure projection whose `modelStarted` is explicitly
false; retain unknown for incomplete historical evidence. No Run, assessment,
receipt, production state or source diagnostic is rewritten.

## Verification

Read the actual schema constant/table/upgrades and the qualification projection
producer before changing prose. The existing false/null API-schema controls and
EN/RU browser journeys remain the executable owners. Scoped links and ADR checks
pass; final complete documentation/contracts validation runs at close-out.

## Prevention

When a diagnostic field becomes nullable or a lifecycle gains continuation,
audit every sibling screen and contract description, not just its first renderer.
Keep source-bound historical receipts distinct from current requirements and
link canonical ownership where duplicated metadata can drift.
