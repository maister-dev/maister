**Severity:** high

## Problem

An independent 4-slice adversarial `/aif-review` after Round 2 surfaced 5 blocking code defects, 5 blocking spec/contract/plan drift items, and 22 medium findings:

1. **Cross-tenant cache key collision & stale `files[]`:** `contentCacheKey(diff, truncated)` omitted `nameStatus` and run/worktree scope even though `entry.files` caches untruncated `nameStatus` metadata alongside the 4 MiB truncated diff prefix.
2. **Spaced and non-ASCII filename breakage:** `sections.ts` did not strip git's literal trailing `\t` on `--- `/`+++ ` headers for paths containing spaces, and `worktree.ts` ran `git diff --name-status` / `--numstat` without `-z`, leaving Cyrillic/non-ASCII paths C-quoted and breaking brace renames (`{ => src}/file.ts`).
3. **Round 2 regression in `useRunStream`:** Keying React state only by `state.runId === activeRunId` without resetting state when `runId` transitions `"run-1" -> null -> "run-1"` (e.g., `Running -> Crashed -> Running` on scratch runs) resurrected stale `liveness`/`error`/`lastEventId` and duplicated replayed `events` for `retain: true` consumers.
4. **Hidden-tab lifecycle defect in `useRunWorkbenchStream`:** Constructed `new EventSource(...)` before checking `isDocumentHidden()`, lacked hidden guards in `fail()` / `reconnect()`, tore down live sockets on `onShow`, and never reset `attempts.current` on `peek.ready` or selection change.
5. **Backend SSE & UI gaps:** `peek/stream` applied pre-DB filtering after the 128-entry `pending` overflow check and checked governance only on `[anchor, selected]` rather than the full `anchor -> ... -> selected` path + mid-stream vault enrollment; `app/api/librarian/stream/route.ts` left an unremoved `request.signal` abort listener; `review-comments/route.ts` parsed body/query before `requireActiveSession()`; `prepareDiff` dropped in-hunk `++`/`--` lines and charged syntax budget for plaintext/0-line files; `cache.ts` lacked a max-entries cap; scratch and specialist-assignment SSE surfaces lacked `<RunStreamLiveness>` / reconnect controls; `WorkbenchGitPanel` spammed 403s for viewers; `TaskLaunchIntentStatus` flashed a duplicate `"Reconnecting"` pill on `"connecting"`.
6. **Spec/contract drift:** `web.openapi.yaml` still cited `lib/diff/prepare.ts` on `POST /review-comments`, missed `400` responses on `/stream` and `/diff`, typed `lastEventId` as integer, and kept `/librarian/stream` tagged `(Designed)`; `docs/db/runs-domain.md` omitted `0368`/`0369`; `docs/screens/chrome/status-bar.md` still attributed socket ownership to `AttentionLiveRefresh`; `docs/system-analytics/workbench.md` exceeded R5a's 12-bullet `## Expectations` cap (15 bullets); the plan claimed `<=2` visible scratch sockets (3 at HEAD) and left an unmeasured multi-tab `pg_stat_database` criterion checked off.

## Root Cause

- **Synthetic test fixtures instead of real `git` output:** Hand-crafted `'+++ "b/dir/my file.ts"'` omitted git's real trailing `\t`, and unit tests lacked Cyrillic filenames and directory-move renames against real `git diff`.
- **Unverified Round 2 refactor edge case:** Replacing synchronous `setState` in `useEffect` with bare `state.runId === runId` lookup missed the `"A" -> null -> "A"` round-trip lifecycle.
- **Partial sibling sweeps:** `useRunWorkbenchStream`, `useStudyStream`, `app/api/librarian/stream/route.ts`, `docs/db/runs-domain.md`, `docs/screens/chrome/status-bar.md`, and `POST /review-comments` OpenAPI prose were adjacent siblings of already-fixed surfaces that missed earlier sweeps.

## Solution

- **Cache & Git Diff Engine (Track F2):**
  - Scoped `contentCacheKey` on `{ scopeKey, diff, truncated, nameStatus }` and `review` cache key on `review:${worktreePath}:${fingerprint}`; added `DIFF_CACHE_MAX_ENTRIES = 256` and `Readonly` return type in `cache.ts`.
  - Added `stripUnifiedHeaderTrailingTab` and `GIT binary patch` early stop in `sections.ts`.
  - Switched `diffNameStatus`, `diffChangeStats`, `diffWorkingTree`, and `diffWorkingTreeChangeStats` in `worktree.ts` to `-z --find-renames` NUL-delimited parsing; added `--no-textconv`, `LC_ALL: "C"`, `MaisterError("CONFLICT")` wrapping, `maxBytes >= 0` validation, and `SIGTERM -> grace -> SIGKILL` timeout escalation waiting for `close`.
  - Fixed `countChanges` in `prepare.ts` (allocation-free `indexOf("\n")` + `inHunk` guard), bypassed Shiki & syntax budget for `"plaintext"` / 0-line files, and exported `DIFF_YIELD_BUDGET_MS`.
  - Moved `requireActiveSession()` before query/JSON parsing in `review-comments/route.ts`, guarded `!run.projectId` in `diff/route.ts`, and hardened `buildReviewPanelData` in `runs/[runId]/layout.tsx`.
- **Backend SSE & Peek (Track F1):**

  - Moved `peekHintSkipReason` filtering into `subscribePeekChanges` before `pending.size >= 128`, tracked full `activePathIds` + pre-emit disclosure check for mid-stream vault enrollment in `peek/stream/route.ts`, added early abort guard in `attention/stream/route.ts`, and switched `app/api/librarian/stream/route.ts` to `AbortSignal.any([request.signal, abort.signal])`.

## Prevention

- Always test git diff/status/numstat parsers against **real `git` temp repos** containing spaced filenames, non-ASCII (Cyrillic) filenames, and directory-move renames (`foo.ts -> src/foo.ts`) — never rely solely on hand-crafted diff fixtures.
- Every cache key whose cached value stores metadata beyond the truncated payload (`nameStatus`) MUST include that metadata and a tenant/workspace scope key.
- When refactoring React hooks away from `setState`-in-effect, always add an `"A" -> null -> "A"` round-trip test alongside `"A" -> "B"`.
- Run an independent adversarial review pass after every remediation commit, and keep every sibling SSE hook (`useRunStream`, `useAttentionStream`, `useRunWorkbenchStream`, `useStudyStream`, `LibrarianProvider`) covered by explicit hidden-tab DOM tests.
