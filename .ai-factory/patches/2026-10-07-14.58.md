## Correction contracts

Create and export job-private Colima and Lima roots before invoking Colima.
Keep Lima's home separate at `runtime_dir/lima`; a nested Colima home would
produce a108-byte SSH socket path on the GitHub runner. Pinned Lima2.2.0
requires the canonical path including its temporary SSH suffix to be strictly
shorter than104 UTF-8 bytes. The actual shell refuses before downloads/start;
no ambient home, shorter external directory or alternate runtime is substituted.
Require the canonical reported socket to equal that root's exact profile
socket; direct foreign paths and symlinked profiles refuse before Docker
contact/export. Declare a single VM upstream resolver1.1.1.1 and preserve
guest resolver/dnsmasq configuration in setup logs. The primary
[directory contract](https://raw.githubusercontent.com/abiosoft/colima/v0.10.3/config/files.go),
[DNS provisioning](https://raw.githubusercontent.com/abiosoft/colima/v0.10.3/environment/vm/lima/dns.go)
and [Lima configuration](https://raw.githubusercontent.com/abiosoft/colima/v0.10.3/environment/vm/lima/yaml.go)
prove how these options are consumed. Guest192.168.5.1 is dnsmasq's own address;
the new option changes its upstream and disables Lima's implicit host resolver.
It does not prove hosted resolver reachability or fix GitHub artifact networking.

A Darwin `EPERM` may be acknowledged only with fresh complete kernel PGID
liveness proof including all UIDs and inspector-marked processes. Existing
invocation snapshots intentionally exclude those entries and are inadequate
for absence proof. A live member, incomplete catalogue or inspection failure
retains the original signal error; the probe grants no signal authority and
does not retry a denied signal per PID. Previously observed survivors remain
leaks after containment. Normal `ESRCH` semantics remain unchanged.
The pinned [kernel group selector](https://github.com/apple-oss-distributions/xnu/blob/xnu-11417.140.69/bsd/kern/kern_sysctl.c#L756-L879)
has no UID or environment filter and includes zombie entries. Its
[process iterator](https://github.com/apple-oss-distributions/xnu/blob/xnu-11417.140.69/bsd/kern/kern_proc.c#L3643-L3729)
omits fork-initialization and shadow representations; this is a fresh group
liveness observation, not an atomic guarantee covering every fork transition.
Existing post-signal ownership and survivor checks remain required.

## Prevention

Verify pinned dependency environment-variable semantics with its source and
actual CLI, including directory existence and independently inherited roots.
Separate group permission denial from kernel-proved concurrent retirement;
never treat an ownership-filtered catalogue as proof of all-member absence.
Audit the matching push attempt as well as the PR run: a preworker network
failure can hide a distinct correctness failure and budget shortfall. Complete
reports, timing headroom and zero leaks remain independent acceptance gates.
