# Activate node-only root budget meters

**Severity:** high.

## Root cause

The sweeper fast path checked only execution-policy and override meters. The later evaluator also enforced declared root delegation budgets, so an empty policy skipped the only code that could apply a node-only limit.

## Fix and prevention

One pure rootDelegationBudget selector now supplies both activation and the existing minimum calculation. Only token, failure and elapsed-time meters activate reconciliation. Nested declarations and admission-only maxChildRuns retain their existing contracts.

When adding a limit source, audit activation, candidate selection, reconciliation and evaluation together; a correct evaluator behind a false early predicate enforces nothing.

## Verification

Two real-Postgres RED cases demonstrate missing descendant-cost reconciliation and a parked root escaping its elapsed-time limit. All 87 owning and aggregation/time-limit checks pass, including nested exclusion and current ownership release. Types, lint and independent review pass. This independent defect is not attributed as the failed GLM qualification cause.
