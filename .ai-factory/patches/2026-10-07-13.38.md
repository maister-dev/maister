## Root causes and repair

- Explicit Darwin PID reads unnecessarily depended on the global process
  catalogue. They now inspect the selected PID directly, retaining both kernel
  reads and exact PID/UID/start revalidation. Full discovery still uses its
  bounded catalogue. An explicitly selected inspector can return its real
  identity, always unowned; snapshots still exclude that helper. Signal
  authority remains exact invocation environment ownership, never path/argv.
- The async native omission log was insufficient when a watchdog immediately
  killed itself. Carry bounded native stderr through the error cause and write
  invocation, expected owner/parent and bounded cause metadata synchronously
  before the same fail-closed self-termination. The exact hosted syscall remains
  unknown; this repairs proved source defects and makes future failure decisive.
- Docker daemon reachability and full SDK construction are different phases.
  Reuse installed Testcontainers10.28.0 strategy/configuration/TLS resolution
  and its Dockerode4.0.12/docker-modem5.0.7 dependency for actual `/info` with an
  abortSignal. Preserve3s default/30s existing known-Docker override. A selected
  failed endpoint refuses immediately. Only a successful daemon probe enters
  public SDK construction, bounded by a separate30s startup ceiling; no late
  success is logged and no database allocation follows rejection. The SDK's
  public discovery has no cancellation API and may finish internally later;
  this does not claim its internal strategy iteration was removed. Review
  this narrow dependency coupling whenever Testcontainers is upgraded.
- Hosted full main migration time totalled377.137s in PR and567.003s on push;
  Brain totalled24.157s/36.549s. Clone overhead was small, and existing suite
  templates already avoided repeated migrations per ordinary case. Keep the
  independent cleanup-control stacks. For fresh main+Brain test databases,
  combine only transport fragments within each committed SQL file. Delegate
  ordering, source hash/timestamp, transaction, ledger rows and idempotence to
  public Drizzle0.36.4 `PgDialect.migrate`/`NodePgSession`; main precedes Brain.
  Preserve production commands and main-only/historical-upgrade helpers.
  SQL/ledger rows roll back on failure; ledger scaffolding remains as in the
  standard migrator. Local elapsed improvement cannot qualify hosted speed.
