# Observe delegated child binding before inspecting recursive Runs

**Date:** 2026-11-04 13:32
**Files:** web/e2e/recursive-harness.spec.ts
**Severity:** low

## Problem

The full browser gate reached `WaitingOnChildren` for the recursive coordinator,
then immediately observed zero physical research-child Runs where two were
expected. The test failed after five seconds before examining descendants.

## Root Cause

The test treated a coordinator's parked state as evidence of physical child Run
allocation. The current completion-obligation contract deliberately includes
accepted, unbound execution-child intents in that state. The actual HTTP root
launch returned 202 and bound successfully in the retained browser trace.
Unlike the separate delegated-Flow fixture failure, the recursive seed already
materializes both installed directories with their result schemas; no recursive
HTTP refusal or missing-directory error appears in the retained Web log.

This establishes the test's premature-observation defect. Whether every child
subsequently binds and completes still requires the coordinated browser rerun;
the failed run stopped before observing that outcome.

## Solution

Wait with the existing bounded Playwright assertion for exactly two research
Flow Runs. Each counted Run must have the selected Flow revision/ref, the actual
parent Run and a canonical execution-child intent whose Run link and immutable
parent proof agree. No intent is fabricated or dispatched by the test. All
existing depth-two agent, result-profile, result-only Done, collect, reduction,
cost and public-result assertions remain intact.

The retained failing evidence is
`/private/tmp/maister-e2e-final-11-10d255160.log` and its recursive trace under
`/private/tmp/maister-e2e-final-11-10d255160-traces/`. Scoped ESLint and diff checks
pass. Browser GREEN remains pending the coordinator's frozen-source gate.
This test-only correction adds no runtime logging or authority exception.

## Prevention

Treat accepted intent, bound Run and dispatched execution as distinct observable
boundaries. A parent waiting for accepted children is not proof of allocation;
inspect the durable associations before asserting on physical descendants.
