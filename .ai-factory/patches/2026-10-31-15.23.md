# Native inspector transport and Librarian connection exhaustion

**Date:** 2026-10-31 15:23
**Files:** `web/test-support/process-invocation.ts`, its O-identity controls and native fixture; `web/components/librarian/librarian-panel.tsx`, its DOM controls and Librarian browser acceptance; ADR-185/191 and the affected system analytics.
**Severity:** high

## Problem

[CI run 41187446088](https://github.com/maister-dev/maister/actions/runs/41187446088), source `8d405e73915e63866546e825d0f30ee8952ee9ab`, failed macOS Intel isolation part 2 and Librarian browser acceptance. The aggregate isolation job then correctly refused the failed part.

## Root Cause

The macOS watchdog immediately failed its process group when one native inspector command exited through `SIGPIPE`. Subsequent kernel-read failures occurred during teardown. The original receipt lacks per-command duration and `killed`, so an inspector timeout is an inference, not established evidence.

Two Librarian panels can hold six HTTP/1.1 connections through attention, conversation and run SSE subscriptions. Completion GETs then wait behind the run streams whose closure depends on those GETs. The panel consumed only the run event count in a `data-events` attribute; run SSE supplies no reply text. A terminal-frame-only workaround still depends on a particular turn being emitted when later queued turns exist.

## Solution

Retry a first native-command `SIGPIPE` once with a fresh kernel inspection. Discard failed output. Keep the original 10-second per-attempt deadline, output bounds, ownership checks and persistent-failure refusal. Record structured attempt, duration, exit code, signal and `killed` without environment data. Real native controls cover recovery, exhaustion, unchanged owned/foreign identities and nonretryable malformed, numeric-exit and `SIGTERM` failures.

Remove the panel's unused run subscription. Existing owner-bound conversation pointers and durable snapshots supply responding state and settled replies, including queued turns. Keep run SSE unchanged for its consumers. Browser coverage verifies two panels, the selected runner, a queued successor, both replies and the preserved second-tab draft. Capture create-command evidence before the successor can become the latest create; select a scripted reply by its unique marker rather than assuming it stays last.

## Prevention

Judge native-command failure separately from ownership evidence; a fresh successful inspection must still prove every identity. Do not treat missing output as an empty owned-process set or retry permission/malformed-data failures.

Audit actual EventSource consumption and per-origin connection capacity across tabs. Cover queue handoff as well as isolated completion. Keep current documentation aligned with rendered behavior; token streaming remains unimplemented.
