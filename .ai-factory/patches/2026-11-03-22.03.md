# Keep operational capability preparation out of delivery Git ignore policy

**Date:** 2026-11-03 22:03
**Files:** web/lib/capabilities/adapter-home.ts; web/lib/agents/launch.ts; web/lib/agents/__tests__/operational-integrity.integration.test.ts
**Severity:** high

## Problem

A real browser fixture completed its optional human assessment, then its
package-backed Claude Triager failed before model dispatch at
`materialization_witness` with `operational_materialization_conflict`.

## Root Cause

The shared capability-home helper copied skills under recorded materialization
leases, then called the delivery helper `ensureWorktreeGitignore`. That second
effect changed source `.gitignore` bytes and index flags outside the recorded
paths. The operational generation check correctly refused the unowned write.

An owned local Git reproducer confirmed this sequence. Its generation failed
with the actual leased paths; a diagnostic comparison allowing only the extra
`.gitignore` path succeeded. That comparison establishes the cause and is not
the production fix.

## Solution

Use separate named operational and delivery entry points over the existing
lease-owned adapter copy primitive. Operational preparation preserves source
ignore policy and index state. Delivery preparation retains its existing Git
ignore behavior. The launcher selects the entry point from the stored agent
kind; no caller-controlled policy flag or integrity exemption is introduced.

The real Git regression checks package skill preparation, successful generation,
unchanged original `.gitignore` and index bytes, cleanup preserving those bytes,
and rejection of a subsequent unowned source write.

## Prevention

- Include every preparation effect when reviewing an integrity failure; a
  platform helper can mutate source outside its declared ownership.
- Keep delivery conveniences separate from operational source preparation.
- Do not whitelist a user file as generated material: removal-based lease
  cleanup cannot restore pre-existing user bytes.
- Verify both the allowed platform write and continued refusal of unowned
  source writes with real Git state.
