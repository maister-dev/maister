# Operational continuation ownership and settlement recovery

**Date** 2026-11-20 18:25

**Severity** high

## Problem

A definitive integrity refusal could still be redispatched after session creation. Settlement could act on a successor assignment, and an undispatched resume could require host inventory before an operator could stop it. A retired predecessor and exhausted settlement also lacked recovery paths for some retained evidence.

## Root cause

Preparation closure occurred at create acknowledgement, before the final integrity check and prompt admission. Teardown performed Run-scoped host effects before checking the settlement claim. Stop performed its host read before checking negative dispatch evidence. Historical repair excluded lost incarnations and required a session-exit event even when a successful checkpoint command had proved retirement.

## Solution

Close the continuation at atomic prompt admission. Persist a late definitive refusal with its turn and session identity, block admission, and guard teardown under the original assignment and settlement claim. Stop and Abandon can finish a proven undispatched assignment under the admission locks. Historical checkout disposal still checks all dispatched predecessors. Exact canonical checkpoint receipts can repair lost records without reopening the session binding.

The Run exposes one settlement incident and its blocker. An authorized recheck consumes the current observation, preserves both attempt counters, and schedules settlement only.

## Prevention

Test both sides of create admission and the race between successor assignment and physical teardown. Verify retained host receipts using the command ledger and exact assignment, epoch, host and session. Scope attention wake evidence to the blocked Run and its bindings. Check UI refresh when attention changes while Run status remains Running.

The sibling sweep used:

```sh
rg -n 'stopCurrentAgentExecution\(|assertAgentCreateNotRefused\(|finishAgentContinuationOnPrompt\(|reconcileHistoricalAgentLifecycle\(|notifyContinuationAttentionChanged\(' web/lib web/app --glob '!**/__tests__/**'
```

The production call sites were the shared finalizer for Stop and Abandon, both fresh and retained create paths, the owned prompt admission transaction, historical settlement and physical disposal, and the three attention state changes. Scope guards keep company and consensus dispatch on their existing ownership paths.
