# Qualify ranking metadata and private-memory isolation at native boundaries

**Date:** 2026-11-09 13:04 UTC
**Files:** web/lib/brain/__tests__/recall.integration.test.ts; web/lib/brain/__tests__/private-memory-isolation.integration.test.ts
**Severity:** low

## Problem

The CB0 traceability matrix named primary tests for CBK-04 and CBE-07 that did not exist. Related tests covered some metadata and private-store behavior, but did not establish the entire native retrieval and migration boundaries.

## Root Cause

Coverage of legacy metadata and private-store owner reads was being treated as evidence for different requirements: ranked retrieval must not confirm knowledge, and Company Brain must not import or expose private memories. Neither inference establishes those boundaries.

## Solution

Add one actual pgvector ranking scenario with high confidence and reinforcement, explicit evidence timestamps and native record/search reads. Repeated ranking must preserve unconfirmed state, unknown attribution/applicability and record observation times; evidence keeps its own source, observation and capture times. Add one real PostgreSQL/filesystem scenario populating the actual private agent and personal librarian stores before Brain migration and replay. Explicit company/project native positive controls must remain readable while private identities and content stay unavailable through native record, witness and search paths; original private owner reads remain unchanged.

## Prevention

Resolve traceability IDs to actual assertions before marking a requirement qualified. Use positive accessible controls beside negative security assertions, and keep migration/import, native disclosure and private-owner behavior in one owning scenario. Do not add duplicate unit tests or rename an unrelated test to fill an ID gap.

## Verification

The four owning integration suites pass 42/42 both in the physically isolated checkout and on the primary checkout. Types, lint and diff checks pass. The initial new-test fixture used an unscoped administrator search; its failure is retained separately and corrected by selecting the intended owner. This is additional qualification of unchanged runtime behavior, not a product RED-to-GREEN claim.
