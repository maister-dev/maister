# Keep bounded native authorization queries out of PostgreSQL JIT

**Date:** 2026-11-09 10:59 UTC
**Files:** web/lib/brain/knowledge-disclosure.ts; web/lib/brain/__tests__/knowledge-query-planning.integration.test.ts
**Severity:** high

## Problem

Parallel evidence/conflict reads of a three-record corpus timed out and disrupted graph-driver renewal while waiting for the consumer Run lock. Live lock observations identified the exact recursive authorization query as the active holder.

## Root Cause

Fresh-table estimates gave the production conflict query a cost of 515859. PostgreSQL compiled 651 JIT functions, spending about 3.37s of its 3.38s execution compiling authorization branches. The same SQL and parameters executed in 0.44ms with JIT off. ANALYZE reduced estimates and avoided JIT in this fixture, but cannot guarantee all future small or freshly populated tables stay below compilation thresholds.

## Solution

Shared native knowledge admission applies SET LOCAL jit=off before any principal branch or consumer lock. Query predicates, permissions, data, statement/lock timeouts and migrations remain unchanged. PostgreSQL restores the prior pooled-session setting at transaction completion. Existing native read/write/proposal/source/cooperation paths share this boundary. The separate company-history policy was measured as low-cost without JIT on a fresh empty-history fixture and remains outside this fix; populated-history performance is not claimed.

## Prevention

Measure the actual production SQL with EXPLAIN ANALYZE instead of assuming a lock timeout is a deadlock or raising timeouts. Compare compilation and execution costs on a fresh schema as well as analyzed data. A deterministic test can force the JIT cost threshold, execute the real authorization query, verify accessible and withheld rows, and inspect compiler use without fragile millisecond assertions. Verify connection-setting restoration after both commit and rollback.

## Verification

Two real-Postgres regressions are RED with compilation present and GREEN with the transaction policy. Five owning knowledge/result/API suites pass 61/61. Type checking, scoped lint and independent adversarial review pass. Safe numeric plan measurements and original live failure/lock observations are retained. This changes neither permission checks nor the separate process-retirement fix needed by the real adapter.
