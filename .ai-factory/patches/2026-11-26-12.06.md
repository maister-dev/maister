# Bind delivery checks to the Run owner and preserve accepted work

**Date:** 2026-11-26 12:06 MSK
**Files:** `web/lib/execution-host/`, `web/lib/agents/`, `web/lib/packages/`, `web/lib/runs/flow-question-lifecycle.ts`, `web/lib/librarian/`, `web/lib/local-packages/`, `supervisor/src/package-skill-home.ts`, Studio and librarian UI, contracts and migration 0375
**Severity:** high

## Problem

A remote Run could pass a smoke gate using evidence from the local supervisor.
Some terminal Flow writers left open human questions for the repair sweep.
The librarian could save an answer and then return a delivery outage as a
failed submission. Package adoption could strand a parked standalone agent.
Studio hid catalog requirements and conflicts behind generic messages.

## Root Cause

The enforcement gate selected a process independently of durable placement.
Some terminal transitions skipped the shared question close, and a failed
repair could roll back later repairs. The answer endpoint mixed a committed
receipt with the post-commit admission hint. Frozen agent targets matched an
attachment projection that adoption is allowed to replace. Catalog errors
carried actionable data internally that the HTTP and UI boundary discarded.

## Solution

Preflight reads evidence from the chosen host. Bound dispatch uses its
assignment, including owned session delivery and recovery. Flow transitions
close their questions in the owning transaction, with bounded per-Run repair
for retained rows. The librarian returns the durable acceptance receipt and
recovers the queued turn. Parked standalone agents can recover the exact
retained MCP descriptor while current attachment, trust and bindings still
authorize it. Published graph loading accepts retired skill settings while new
authoring and publication enforce the current schema. Studio presents bounded
catalog reasons and uses the shared diff renderer. Migration 0375 enforces
the existing capability-ref grammar for package MCP scope overrides.

## Prevention

Sweep assignment-sensitive probe callers with
`rg -n 'assertEnforcementEvidence\(|assertCapabilityGuardEvidence\(|assertReadOnlySession(Create)?Evidence\(' web/lib`.
Prove refusal with the local smoke gate ready and the selected supervisor
missing evidence. Exercise a claim against its original assignment after
changing the preferred host. Test saved answer replay and terminal closure
against PostgreSQL. Verify human answer races, stable acceptance while the
host is unavailable, and the current authority checks on frozen MCP material.
When an integration sends a new request after Flow parking, wait for both
the parked status and release of the driver token. The status can commit
while driver cleanup still holds the Run row.
Keep historical migration and qualification receipts pinned to their commits.
