# Preserve localized delivery terminology while refreshing stacked review PR

**Date:** 2026-10-30 09:13
**Files:** web/messages/ru.json
**Severity:** low

## Problem

The published `split/review-workspace-focus` branch for PR #34 was marked conflicting with current `master`. The only conflict was a shared Russian portfolio translation block.

## Root Cause

The review branch changed delivery terminology inside a broader translation hunk while `master` retained older neighboring wording. Git could not merge the adjacent edits even though the `workspaces` key itself already had the same value on both sides.

## Solution

Merged current `master` without rewriting the draft branch and retained the review branch's final delivery terminology: `Автоматически доставлено` and `Недавно объединено`. Verified EN/RU parity and review/HITL behavior with focused tests, then ran documentation, contract, TypeScript, supervisor, and MCP gates under Node 24.19.0.

## Prevention

- Keep translation changes narrowly scoped to the keys whose terminology changes.
- Refresh stacked branches after their prerequisite PRs land; repeat the final rebase after #33 merges as already documented in PR #34.
- Run locale-specific behavior tests in addition to structural i18n parity checks.
