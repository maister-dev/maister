# Observatory agentization final-hardening

## Problem

Review remediation initially covered delivery matching and provenance recovery,
but end-to-end validation exposed three contract edges: budget events were
windowed by insertion time, an Observatory filter assertion could match
decorative flow chips, and an ICU freshness label was resolved without its
required value.

## Root cause

The budget read model used `domain_events.created_at` instead of the event's
authoritative `occurred_at`. The browser test used a broad accessible-name
locator. The server translation helper attempted to materialize an ICU message
without arguments; replacing it with a function then violated the Server to
Client serialization boundary.

## Solution

- Window budget events on `occurred_at`.
- Scope the E2E flow and node assertions to their textbox roles.
- Keep the freshness label serializable as a localized prefix and compose the
  formatted timestamp in the client component.

## Prevention

For read-model time windows, use the domain event time rather than database
insertion time. Keep Server Component label DTOs data-only, and exercise
translation placeholders in browser coverage whenever labels cross that
boundary. Prefer role-specific E2E locators when a label is also used by
non-control content.
