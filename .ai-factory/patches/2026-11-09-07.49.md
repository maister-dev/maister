**Date:** 2026-11-09 07:49 UTC

**Severity:** high

## Problem

Accepted child launches became permanently held after ordinary parent-row contention, and an agent could record failed preparation before first model dispatch. Two oldest-100 recovery sweeps indefinitely hid later valid work. A correction with retained missing evidence failed client validation. Russian views displayed generated English diagnostics. Current migration/deployment/status documentation retained pre-rebase identifiers and pre-implementation claims.

## Root Cause

- A new typed busy conflict reached existing permanent-failure classifiers at five lifecycle seams; the inner agent catch ran before outer yield handling.
- Recovery capped each scan without durable rotation. A moving tail also postpones revisiting restored older work indefinitely unless a cycle has a frozen high-water boundary.
- Form validation inspected only newly typed text before assembling retained declarations.
- Generated diagnostic prose was mixed with authored limitations and rendered verbatim. Exact-string translation alone would alter an author's identical submitted text.
- Phase-0 migration prose/statuses were not reconciled with applied journal tags and implemented writers; generic docs validators checked syntax/links, not this semantic mapping.

## Solution

Use one precise typed contention predicate throughout claims/preparation/dispatch, preserve durable identities and attempt budgets, release physical preparation before yield, and let existing continuation recovery retry. Persist independent versioned CAS keysets and fixed microsecond creation boundaries in the existing scheduler target; targeted wakes bypass them. Validate the assembled form declarations without strengthening shared API rules. Project trusted legacy diagnostics to typed read codes and localize them separately from authored content; leave immutable storage/input/finding contracts unchanged. Reconcile the current DB/analytics surfaces and amend historical ADR status context without rewriting decisions. Add a journal-backed manifest check.

## Prevention

Re-derive the complete producer-to-consumer path when introducing a typed yield. Exercise actual locked rows at every distinct claim/bind/dispatch boundary, including materialization before create/prompt. Qualify recovery with more than one full page, revoked rows, new arrivals, wrap, targeted wakes and stale cursor writers. Keep system diagnostics structurally distinct from authored bytes and verify both languages through actual browser paths. Validate migration names against journals after integration; classify numbered/status references as current or historical before changing them.
