# Make native result object levels explicit

**Severity:** medium.

## Root cause

Two actual GLM-5.3 results placed selection inside each finding and were correctly rejected. The shared instructions juxtaposed finding.sourceFindings and result-root selection without making their levels explicit; the package coordinator also said only to add selection.

## Fix and prevention

Keep the closed validator unchanged. State the exact object level in the shared native grammar and every self-contained package role/Flow. Supply one typed, executable nonempty example with empty citations and explicit missing evidence so valid shape never requires invented source IDs. Keep reduction accounting separate from finding content.
