# Stage C review fixes after rebase

**Date:** 2026-11-26 19:03  
**Severity:** high  
**Files:** `web/lib/reconcile.ts`, `web/lib/flows/graph/runner-graph.ts`,
`supervisor/src/workspace-publish.ts`, `supervisor/src/workspace-git-checkpoint.ts`,
`supervisor/src/workspace-prepare-api.ts`, and the owning Stage C contracts and tests

## Problem

Reconcile could classify a live host-owned Flow as missing its checkout or
skip it when the default Supervisor was unreachable. Confirmed Git ref
rejections held writer claims. Workload command completion and the proof that
its process group had retired shared one result field.

## Root cause

An empty manager path and a default-host inventory were treated as facts
about addressed assignment owners. Git recovery did not distinguish a
definitive refusal, an observed result, and an interrupted mutation. Failure
after process retirement could hide physical quiescence behind output sealing.
An internal retirement field added to SQLite receipts also needs to be removed
by the strict public receipt serializer.

## Solution

- Reconcile addressed Runs by persisted assignment and workspace ownership.
- Retry the original Git command under its retained claim. A definitive
  publication refusal needs the exact ref rejection and readback of its lease.
- Record process-group retirement before sealing workload outputs. Keep
  that witness private and retire an authorized workload on IPC disconnect.
- Read sealed context declaration bytes through the existing digest check.
  Apply kernel write protection to workloads on a read-only checkout.
- Treat a complete NUL-terminated Git porcelain record as proof of a dirty
  workspace even when a larger change list exceeds the output budget.
- Qualify owning Stage C integration suites without an opt-in PR label.

## Prevention

Search `rg -n 'requireProjectFlowRun\(|workspaceProcessRetired|readVerifiedInputFile\(' web/lib/flows/graph/runner-graph.ts supervisor/src` when changing either boundary. Repository-owned nodes use repository identity. Workspace-specific Git paths keep their legacy guards, and selected-host consensus is refused during launch. The process-retirement witness has two host-side writer predicates and one public receipt exclusion. Exercise the strict Web decoder against the real Supervisor response.

Keep the original migration test evidence with its historical numbering. The
current journal and preserved SQL bodies establish the rebased lineage.
