## Problem

A full /aif-review of `feature/evaluation-lab` (8 parallel review agents) found blockers beyond the earlier remediation: dead `review_required→terminal` FSM edges, no crash recovery for `capturing/checking/aggregating`, a poison race terminalizing live executions, seal without status-CAS, five launched-lineage escape hatches (participant hard-delete, restart, sync, GC, unwired `evaluation_study` hold), unvalidated verdict `participantIds` enabling a cross-project recipe pull, method-revision upsert mutating in-flight executions, plus UI (SSE replay loop, verdict dead-ends, dead `forest-*` tokens) and docs drift.

## Root Cause

The feature was built subsystem-by-subsystem with strong local patterns (CAS, append-only, snapshots) but the SEAMS between subsystems were unowned: FSM edges declared with no driver, guards validated-at-write but unenforced-at-read (write-only snapshots), lineage predicates migrated at four consumers but not the fifth/sixth (sync, GC), and "immutable" enforced by convention where an upsert path existed. The review's adversarial-invariant pass (attack every documented MUST across sibling subsystems) found the class that per-subsystem review missed.

## Solution

Seven parallel fix agents with disjoint file ownership (dispatcher A; judges/schema B1; governance B2; lineage C; UI D; docs E; ext/tests F), cross-agent contracts pre-agreed in prompts (`openReview(args, db?)`, digest function signature). Three agents (A, C, D) were killed by the account session limit mid-run WITHOUT final reports — their work was verified complete by direct inspection: one-error typecheck (a stale test fixture), 4 failing tests, all four traced to test bugs, not code bugs: (a) 3 renders missing the new `FeedbackProvider` wrapper; (b) a GC test seeding runs 8 days old against `DEFAULT_GC_AGE_DAYS = 14` — piecewise SQL-predicate instrumentation isolated the cutoff as the excluder. Final: 365/365 evaluation tests green, both typechecks clean, validate:docs/contracts pass.

## Prevention

- When a subagent dies without reporting, do NOT re-run it blind: typecheck first (one compile error localizes the frontier), then run its test files — a killed agent's failures are usually test-fixture bugs at the very end of its work, not missing implementation.
- Debugging a 0-rows-selected query: replicate the WHERE piecewise in the test (base predicates, then +1 guard at a time) — it localized a wrong-constant assumption (7d vs 14d GC horizon) in two runs.
- `pnpm <cmd> | tail` LIES about exit codes — `set -o pipefail` or check the tool-level exit; a "passing" suite hid 4 failures behind tail's exit 0.
- Prose claims of retention windows ("7d" in CLAUDE.md) must be checked against the config constant (`DEFAULT_GC_AGE_DAYS = 14`) before being baked into test fixtures.
- Parallel same-tree agents work IF file ownership is disjoint and cross-file contracts are stated in both prompts; the two mid-flight contract landings (throttle, verdict gate) were absorbed by the consuming agent re-reading, not by coordination overhead.
