# Retry busy session evidence and release failed Flow readers

**Date:** 2026-10-01
**Files:** canonical session content/stream, Flow runner and owning integration controls
**Severity:** high

## Problem and cause

Hosted run 36858618377 failed to observe an initial gate permission before
its intended claim-SIGKILL cut. Its swallowed child output prevents an exact
hosted root-cause attribution. Local investigation reproduced a reachable
strand with a real supervisor: two unread object responses occupy the host's
read cap, so the session event reader receives `command_in_progress`.
The Flow consumer logged the failed read and stopped, leaving its accepted
prompt waiter alive with no reader able to deliver the permission.

## Solution

The shared session-content reader retries only the typed busy refusal, with
five attempts and abortable 100/200/300/400 ms delays inside the caller's read
deadline. It logs refusals and throws the last error on exhaustion. Digest,
length, identity and fence validation remain mandatory. Non-busy errors and
cancellation still propagate. The ephemeral cursor advances after successful
preparation. A failed Flow reader aborts its existing failure signal, causing
the accepted prompt to yield to durable continuation without admitting a
replacement prompt.

The gate fixture now exposes child/claim output and command-state diagnostics
when an assertion fails. Its two added schedules fill the actual host read
cap with real responses; a proxy holds requests and forwards real busy
responses unchanged. They prove both transient recovery and exhausted-reader
reattachment. Detached children, held responses and continuation workers are
settled by the case.

## Prevention

Treat a bounded host refusal as retryable evidence access, not absent evidence.
A logged-and-abandoned reader cannot own a live waiter. Tests invoking a
durable driver must distinguish yielded work from completed work and settle
their own continuations before ending. Do not equate a reproduced related
defect with an unobserved hosted cause.
