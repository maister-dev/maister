# Seed the actual owner of a delegation token

**Date:** 2026-11-04 09:48
**Files:** web/test-support/delegation-seed.ts; local coordinator fixtures in web/app/api/v1/ext/runs/__tests__/{delegate,plan,message,star-routing,child-run-id-contract,promote-rework}.integration.test.ts
**Severity:** medium

## Problem and cause

The shared coordinator fixture inserted an agent Run, then requested an
orchestrator token. The token minter correctly requires a current Flow Run for
that token family. Delegation controls stopped at `token_run_binding_invalid`
before reaching their intended launch, refusal or replay boundary.

## Correction

The fixture now inserts a Flow Run with no catalog agent identity and a Flow
version label. Its project, status and parent/root lineage remain unchanged.
The legacy `orchestratorAgentId` argument remains only for caller compatibility;
it supplies no identity or authority. Bounds still come from persisted Run
snapshots and ancestry. The fixture deliberately remains unpinned so the
existing missing-result-profile-pin refusal stays meaningful; supplying a
default revision would erase that negative case.

The same correction applies to the local coordinator factories in the delegate,
plan, message, star-routing and promote/rework suites, including the nested
coordinator and child-ID fixture's parent. Their agent children retain their
actual agent identity. Existing stale-token controls already mint while the
owner is active, then apply the terminal transition before invoking the route.
The collect-v2 suite uses the shared fixture and needs no separate setup edit.

## Validation

RED is retained in `/tmp/maister-token-minter-consumers-30.log`. The existing
real-PG Flow delegation suite passes **23/23** in
`/tmp/maister-delegation-seed-flow-owner-green.log`, including authorized Flow
binding, agent facade targeting, cross-kind capacity, competing/replayed keys,
changed-payload refusal and required-audit rollback. Its database stopped.
Scoped ESLint and `git diff --check` pass. No production token check, fallback,
test assertion or revision pin was changed. Other independent token fixtures
need their own scoped corrections and are not qualified by this result. The
seven local coordinator caller files (including collect-v2 through the shared
seed) pass **82/82** in
`/tmp/maister-local-coordinator-token-owners-green.log`; all seven databases
stopped naturally. Their actual agent-child identities, stale-parent terminal
transitions, message/park, collection, root-versus-nested promotion and malformed
child-ID assertions remain intact. Scoped lint passes for the entire cohort.
