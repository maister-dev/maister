# Keep packaged skills readable within run workspaces

**Date** 2026-11-21 20:43

**Files** `web/lib/capabilities/package-skills.ts`, `web/lib/capabilities/adapter-home.ts`, `web/lib/capabilities/materialize-bundle.ts`, `web/lib/agents/launch.ts`, `web/lib/agents/launch-contract.ts`, `web/lib/flows/runner-agent.ts`, `web/lib/scratch-runs/service.ts`

**Severity** high

## Problem

MAI-11's Triager tried to load `task-qualification/SKILL.md` before inspecting the task. The filesystem MCP connector denied the path under the run's redirected Codex home. The result validator also refused the resulting blocked payload because `not_started` coverage carried nonzero work counts.

## Root cause

The adapter's native skill discovery path and the connector's workspace read root serve different purposes. An operational Codex home is a sibling of the detached checkout so its configuration and credential links stay outside the worktree. OpenCode and MiMo also use redirected homes. The launch prompt gave the agent no workspace-readable path to the skill. The operational completion appendix did not explain the zero-count requirement for setup failures before the first scan.

## Solution

Project the installed skill directory and its companion files into a lease-owned workspace directory. Advertise the relative paths in newly prepared standalone, project Flow and scratch prompts. Preserve adapter-native registration and keep redirected operational homes separate. Store scratch launch redirects for respawn. Clarify `not_started` in the completion appendix and accept the supported historical digests.

## Prevention

Exercise the filesystem connector against the path in the actual prompt and check that the same connector denies the redirected home. Cover all adapter layouts, a repository-local skill with the same name, an escaping companion link, operational worktree integrity and scratch respawn.

```sh
rg -n 'materialize(Operational)?AdapterCapabilityHome\(|materializeWorkspacePackageSkills\(|workspacePackageSkillsPrompt\(' web/lib
```

The adapter-home caller set includes standalone agents, project scratch and the package assistant. Project Flow launch and rewind use the bundle materializer. Company Flow and Librarian currently supply no package skill set.
