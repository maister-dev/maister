# Preserve budget stop ownership until physical teardown settles

**Date:** 2026-11-10 12:48
**Severity:** high
**Files:** `web/lib/runs/budget-termination.ts`, `execution-policy.ts`, `keepalive-sweeper.ts`, `state-transitions.ts`; shared graph driver, agent finalization, scratch terminal and owned-prompt admission seams; owning integration fixtures.

## Problem

A budget watcher deleted a live session before committing its terminal outcome. The interrupted ACP prompt or native scratch exit projector could terminalize the Run first, replacing the deliberate budget outcome with a protocol error, crash or review and releasing its owner.

## Root Cause

Physical teardown and terminal CAS were intentionally ordered to prevent a false terminal state while a process remained live, but no durable cause owned the interval between them. The original budget verdict could also disappear after a retryable teardown, and a stale warning could overwrite its state.

## Solution

Retain a typed server-owned pending stop in existing `runs.budget_state`, separate from `notified` and terminal status. Serialize with the Run lock; preserve the verdict across uncertain teardown; validate applicable assignment, driver, attempt and canonical session identity before settlement. Shared traversal, terminal finalizers, native scratch terminal projection, agent parks, permission intake, crash recovery and new prompt admission respect that owner. Lower budget rungs cannot erase it. Both shared HITL creation variants refuse a current stop within the caller transaction, rolling back a competing pause/question and its temporary artifact. The legacy permission fallback rechecks in its own transaction after the owned probe.

Refuse a new stop over an already terminal current-owner prompt, including when the host session is absent; replay an existing budget stop before that check. Superseded ownership never inherits the old intent. Every thrown DELETE refusal retains pending ownership; only positive stopped/gone outcomes or observed absence permit settlement. Company cancellation and budget-stop claims use first-intent ownership under the existing Run lock.

## Prevention

Before an external teardown, persist its cause and exact applicable ownership without declaring success. Audit every same-session terminal writer, including independent event projectors and legacy consumers; ordinary exception finalizers alone do not close the race. Keep retries, current authority and physical quiescence as distinct obligations.
