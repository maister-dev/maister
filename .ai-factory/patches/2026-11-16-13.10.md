# Package 3 acceptance fixes

**Date** 2026-11-16 13:10
**Files** `web/lib/agents/preparation-workspace.ts`, `web/lib/queries/run-timing.ts`, `web/lib/execution-host/retirement.ts`, `web/lib/queries/runs-list.ts`, `web/components/ui/local-time.tsx`, `web/lib/tasks/external-source/closing-reference.ts`, and their browser and integration suites.
**Severity** medium

## Problem

The Playwright gate found a cold manual-agent launch failure, duplicate streamed locators, and a keyboard assertion before hydration. Desktop Runs filters overflowed. Desk and the task page disagreed on the timezone of one completion event, and the Runs ledger did not show that event. Review also found queue time in agent execution totals and unchecked repository text in generated PR closing directives.

## Root cause

- Plain-directory preparation validated a configured root before first use created it. The agent browser fixture held the legacy exit stream even though terminal prompt evidence could already finish the Run.
- Turn creation represents queue admission. Accepted prompt commands carry the host admission timestamp, and a successful terminal receipt can carry it when the acknowledgement is lost. Command retirement compacts that receipt.
- Runs filters used nine tracks with fixed minimum widths inside a shell with rails. The activity title used the server timezone. The LocalTime component could read the previous document language during a client locale change.
- Source scope is opaque for task identity. The closing-reference helper consumed it as a GitHub repository name without a syntax check.

## Solution

Initialize the manager runtime before taking a plain-directory fence and retain the existing path checks. Hold the controlled prompt while the test reads the visible project workspace panel. Scope streamed page locators to main and verify the hydrated timing button before keyboard input.

Use prompt admission and settlement evidence for agent and scratch timing. Save verified receipt admission in the retirement tombstone. Project the completion activity timestamp by task, project, and Run. Render it with a reactive app locale and browser timezone. Let the filters fit the available width and show a dash for missing token measurements.

Validate GitHub repository scope at the shared closing-reference generator. Promotion, the Workbench draft, and Workbench PR creation all use that generator.

## Prevention

Keep cold-root and symlink coverage in the preparation suite. Exercise timing with accepted, queued, receipt-only, and retired prompt evidence. Compare the same stored completion event across task, Desk, Activity, and Runs in a fixed browser timezone, then switch language in place. Keep malformed scopes in the pure closing-reference table.
