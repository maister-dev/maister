**Severity:** high

## Problem

Adversarial `/aif-review` over `optimize_browser_sse_shiki` surfaced 14 blocking defects across four areas:

1. **Backend SSE security & invalidation drops:**
   - `/api/runs/[runId]/stream` froze `isGoverned` once at connect time, so a `Pending` run or multi-node Flow that inserted `agent_memory_injections` mid-stream skipped per-batch disclosure verification for up to `2,500 ms`.
   - Projectless runs (`projectId === null && companyId === null`: librarian & local-package assistant) skipped active-user re-checks inside `verifyStreamAuth`.
   - `/api/runs/[runId]/peek/stream` keyed its `pending` coalescing map without `hint.source`, letting `execution_events`/`runs` overwrite `node_attempts`/`workspaces` and get dropped by the pre-DB filter; `foreign_root_run` dropped reparented grandchildren before `belongs(previousParentRunId)` ran; and governed/company runs coalesced auth rechecks to `2,500 ms` instead of re-verifying before emit.
2. **Diff cache staleness/poisoning & quoted-path corruption:**
   - `RunDetailLayout` interpolated mutable `detail.baseBranch` into the `sha:` LRU cache key when `baseCommit` was null and stored truncated `prepared.files` under the same key where `/diff` stored full `diffNameStatus` files; `diffRunWorkspace` vs `diffRange` passed mismatched git diff flags (`--no-color` vs `--no-ext-diff`).
   - Duplicated `parsePath` in `line-index.ts` and `prepare.ts` broke git C-quoted paths (`"a/dir/my file.ts"` → `'file.ts"'`) and was masked by a parity-only test; `run-diff-source.ts` and `review-source.ts` still imported `filterDiffByPath` from `prepare.ts`.
3. **Client SSE & React lifecycle regressions:**
   - `AssignmentLiveRefresh` included `liveness` in its refresher effect deps, aborting the final completion check the moment a terminal run closed SSE.
   - `ScratchConversation` wired `loadDetail` (which clears `error` alerts) into the 250 ms coalesced refresher and re-triggered `/capability-catalog` via `detailRevision` on every SSE tick (12 req/s storm), plus wrapped `useRouter()` in `try/catch` (`useOptionalRouter`).
   - `TaskLaunchIntentStatus` double-fired `onRefresh()` on mount under the already-live shared `AttentionStreamProvider` and kept polling after `complete`.
   - `useRunStream` leaked `lifecycleRef`/retry attempts, `events`, `eventCount`, and `error` when switching `runId` A → B.
4. **SDD contract & doc drift:** `web.openapi.yaml` promised raw `diff` on `prepare-failed` and drifted on SSE paths; `run-peek-data.md` claimed `+ 15 s heartbeat` auth rechecks (contradicting transport-only heartbeats); `workbench.md` breached R5a (16 bullets in `## Expectations`) and had a wrong scratch Mermaid diagram.

## Root Cause

- **Connect-time snapshots of mutable security state:** Computing `isGoverned` once at HTTP connect assumed vault enrollment is static for a run's lifetime, ignoring runs that stage vault memory after `Pending` or on later graph nodes.
- **Unkeyed coalescing & cross-caller shared cache keys without a canonical producer contract:** Coalescing maps and shared caches silently collide whenever two writers produce structurally different values under the same key (`hint.source` omitted from `pending`; `prepared.files` vs `diffNameStatus` under `sha:`; mutable branch names mixed with commit SHAs).
- **Side-effect coupling in React effects:** Putting transient transport state (`liveness`) into refresher ownership deps or coupling static catalog fetches to a transcript-mutation counter (`detailRevision`) amplified harmless re-renders into aborted completions and fetch storms once trailing debounce starvation was fixed.
- **Partial spec sweeps:** Updating `RunDiffResponse.required` and AsyncAPI without sweeping sibling OpenAPI descriptions (`renderUnavailableReason`, SSE route entries) and R5a bullet counts left contradictory contracts.

## Solution

1. **Backend SSE (`F1`):** Re-check `isRunGoverned(runId)` dynamically before enqueueing outgoing frames when `!governed`, promote `governed = true`, and verify immediately; enforce `requireActiveUserById(userId)` for projectless runs; verify auth before final terminal batch emit; include `hint.source` in `/peek/stream`'s `pending` key; bypass `foreign_root_run` when `previousParentRunId !== parentRunId`; bypass `2,500 ms` auth coalesce for governed/company runs in `/peek/stream`; harden `finish()`/`heartbeat` `try/catch` and add `ReadableStream.cancel()` to `/attention/stream`.
2. **Diff Engine & Cache (`F2`):** Extracted pure `web/lib/diff/sections.ts` (`splitSections`, C-quoted `unescapeGitQuotedPath`/`parsePath`, `repoRelPath`, `filterDiffByPath`) shared by `prepare.ts`, `line-index.ts`, `run-diff-source.ts`, and `review-source.ts` (decoupling `shiki` from review-comment imports); standardized `--no-color --no-ext-diff --end-of-options` across all git diff readers; resolved immutable `baseSha` and `headSha` + full `diffNameStatus` in `RunDetailLayout` before caching; passed `headSha` to git readers in `diff/route.ts` to close live-commit TOCTOU; skipped per-file >2,000-line sections in `prepare.ts` without latching `budgetExhausted`; hardened `cache.ts` oversize overwrites and `byteSize` validation.
3. **Client SSE & UI (`F3`):** Removed `liveness` from `AssignmentLiveRefresh` refresher deps and reset `unavailable` on scope change; switched `ScratchConversation` to unconditional `useRouter()`, `fetchDetail(signal)` in the coalesced refresher, and decoupled `/capability-catalog` & `/commands` from `detailRevision`; tracked `seenTickRef`/`prevLivenessRef` + `complete` in `TaskLaunchIntentStatus`; reset all run-scoped state on `runId` A → B switch and deduplicated visibility-resume `session.stream_ready` in `useRunStream`; synced `LiveRunInspector` state on `runId`/terminal prop updates; reused `createCoalescedRefresher` in `RunLiveRefresh` and `FlowGraphView`.
4. **SDD Contracts & Docs (`F4`):** Reconciled `web.openapi.yaml`, all 3 AsyncAPI specs, `workbench.md` (11 bullets in `## Expectations`, fixed scratch Mermaid), `run-peek-data.md` (removed false heartbeat auth claim, added `0368`/`0369` + 7th source), `review-comments.md`, `attention.md`, `librarian-conversation.md`, `runs.md`, `scratch-runs.md`, and `database-schema.md`.

## Prevention

- Never freeze security-classification booleans (`isGoverned`) at SSE connect time when later execution stages can enroll the run; re-check before enqueueing and test mid-stream enrollment + projectless user deactivation explicitly.
- Every coalescing map key MUST include every discriminant that downstream filters branch on (`hint.source`), and every shared cache key MUST enforce identical producer semantics (`baseSha`/`headSha` resolved to SHAs, identical `diffNameStatus` file list, identical git flags).
- When fixing trailing-debounce starvation on a React refresh hook, audit every `useEffect` downstream of the refreshed revision counter to ensure static/expensive fetches are not accidentally amplified into a polling storm.
- Never wrap React hooks in `try/catch` to appease a test missing a `next/navigation` mock — fix the test mock instead.
- Parity tests between two parsers must assert the **actual parsed keys/values**, not only equality with a reference parser that shares the same helper bug.
