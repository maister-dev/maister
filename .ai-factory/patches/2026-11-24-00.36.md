# Bind addressed operations to resolved workspace targets

**Date** 2026-11-24 00:36 MSK

**Files** Stage C profile, examples, validator, analytics and implementation plan

**Severity** high

## Problem

The Stage C draft could not resolve a lost acceptance or retrieve a typed
result. Its replay test could accept a changed URL target. It also coupled
host ACK to projection and allowed an unproved expiry to release a writer.

## Root Cause

The draft reused legacy endpoints with different success shapes. Receipt
evidence had no acceptance or result arm, and its canonical identity omitted
the address. Both operation inventory and coverage came from the same
fixtures. Host transport continuity and domain application were treated as
one checkpoint.

## Solution

Use negotiated versioned routes, canonical target binding and typed receipt
phases. ACK contiguous ingest independently of owner projection. Require
positive owning-host quiescence before explicit recovery. Define project
default and preview authority, revision CAS and board recovery states.

## Prevention

Keep an independent operation inventory and validate exact status, typed
refusal, timestamp, resolved target, receipt digest and event correlation.
Cover the lost acceptance and terminal readback as well as the unchanged
legacy route. For placements, test a poisoned projector and a live process
across a partition.

The sibling sweep used `rg -n 'before ACK|command_digest_mismatch|/workspaces/\{id\}|lease_expires_at' docs/api docs/system-analytics docs/db .ai-factory/plans/feature-stage-c-selected-supervisor.md`.
Legacy lookups stay on their existing paths. Versioned operations carry the
addressed receipt. Worker leases still fence short DB work, while physical
writer release depends on observed quiescence.
