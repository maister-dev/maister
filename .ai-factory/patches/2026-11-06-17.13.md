# Read only canonical controlled-supervisor session records

**Scope:** the shared browser fixture session reader and its five existing consumers.

Both controlled supervisors create session snapshots named exactly `<session-uuid>.json`, with `sessionId`, `acpSessionId`, `request` and `prompts`. Other fixture artifacts can share the directory. A filename ending in `.json` alone does not identify a session snapshot.

The combined browser lane at `dad2c003c6019463651003f3edcd8057eb98ca39` reached actual qualifier acceptance and a Running candidate before UX04's reader failed on `record.request.runId`. The manual PR journey failed at the same broad directory scan. Five `<session>.<command>.recursive-turn.json` files remained from the earlier diagnostic invocation `0919187f-e15d-46ce-bb29-cb15b799cac3`; they were safe diagnostic records without a `request` field. The diagnostic producer had already been removed, but those files remained in the shared fixture directory. This was diagnostic namespace leakage and an overbroad test reader, not a Triager or runner refusal.

One reader now recognizes the producers' exact canonical filename and validates the real session-record schema plus filename/session identity. Malformed canonical records throw a safe, explicit fixture error; they are never silently skipped or treated as optional requests. Request fields and prompt bodies remain private test data, and invalid record contents are not included in errors. All five broad-scan consumers use this reader, retaining their original runner, read-only, qualification, prompt and release assertions.

A real temporary-directory dataset reproduced three failures before the fix and passes all three afterward: canonical/sidecar separation, malformed canonical refusal, and filename/identity mismatch. The new reader also validated all 143 retained canonical snapshots without exposing their contents. The only five removed files were verified against their original diagnostic Run/command/session identities and hashes; a safe manifest is preserved at `/private/tmp/maister-r21-stale-sidecars-manifest.json`. No other session record or marker was removed.
