# Scratch transcript lock compatibility and real rework lifecycle

**Date:** 2026-10-02
**Severity:** high
**Files:** `web/lib/scratch-runs/{turn-completion,service}.ts`, scratch permission/queue concurrency tests, `web/lib/agents/__tests__/prompt-owners.integration.test.ts`, CI diagnostics.

## Problem

Hosted run 37010985789 could not persist S3's permission, failed one agent
rework case, exhausted Intel's slice budget, and failed the Librarian runtime
probe before browser tests started.

## Root Cause

The permission writer held `runs FOR UPDATE` while waiting for the transcript
allocator. Canonical projection already held that allocator and inserted a
message whose run foreign key needed `KEY SHARE`. PostgreSQL detected the
cycle; the error path cancelled the supervisor deferred. The service's private
copy of the lock helper had the same exposure when queuing a recovery message.

The rework fixture independently violated the real lifecycle: a plain agent
finished Done and scheduled directory removal, then the test rewrote it to
Review and reworked it. A genuine worktree-backed Review retains its directory.
Hosted SPAWN timing is consistent with overlapping cleanup, but the log omits
the errno; missing cwd is not claimed as a proved hosted syscall outcome.

## Solution

Use the existing project's `FOR NO KEY UPDATE` convention for non-key run
authority writes, retaining run-before-scratch ordering and exclusive writers
while allowing the projector's foreign-key check. Reuse that shared helper
from all six service callers. Rework tests now reach Review through the real
launcher and retain the original result/revision and exactly-once assertions.

No API or database-schema changes are required. Existing status/error enums,
CI platform and deadlines remain unchanged. The Librarian step enables only
the Testcontainers core diagnostic namespace; this diagnoses the next runtime
initialization failure and is not a claimed fix for the unknown hosted cause.

## Prevention

When a row lock also surrounds child inserts or an allocator, include foreign
key locks in the lock graph. Grep for private copies of the helper and for
test observations that match its SQL text. Keep physical test blockers
distinct from production-lock observation predicates. Do not manufacture a
state that its production lifecycle never reaches to exercise a continuation.

The native inspection optimization was measured and rejected as immaterial to
the suite budget. Local green runs cannot resolve hosted Intel timing or an
unobserved Docker initialization subphase; these remain S5.3a inputs.
