# Canonical Create Flow Verification Fix

## Root causes

- Studio passed ICU templates through `t()` before the component that supplies
  their interpolation values, causing runtime formatting failures.
- Browser fixtures registered temporary directories as Git sources even though
  the current source contract requires the explicit local-directory kind.
- A package-attach fixture still used the retired `steps:` Flow shape, so it
  failed before reaching its schema-reference assertion.
- Recovery and route tests did not directly cover hash-proven replay, drift,
  redundant identifiers, or refusal before mutation.

## Preventive checks

- Retrieve delayed ICU templates with `t.raw()` and test the receiving
  component's interpolation boundary.
- Make E2E helpers select the source kind that matches the supplied fixture.
- Keep non-legacy package fixtures graph-only; retain a deliberate `steps:`
  fixture only when the test asserts the graph-only rejection.
- Include recovery replay/drift and identifier-authority refusal in the focused
  local-package lifecycle suite.
