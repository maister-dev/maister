**C2. The anchor source is already kind-branched.** `reconcile.ts:1725-1728`: `cand.runKind === "agent" || cand.projectId == null ? cand.runStartedAt : await latestAttemptStartedAt(db, cand.runId)`. Agent runs and **project-less** scratch runs are anchored on `runs.started_at` (so a project-less Recover is already past grace); **project** scratch runs read `node_attempts` and get `null`. `evidenceClassification` returns null for every non-flow run (`:578`) and `crashRecoverPending` is flow-only (`:1791-1794`), so a scratch run without a live session lands on `grace-window` or `agent-session-gone` — nothing else. **C3. `classifyScratchRecovery` ignores `runStatus`** (`recovery.ts:13`, `:31-48`): the predicate is workspace removed → `none`; dialog `Done|Abandoned` → `none`; `Review` → `open`; live host session → `open`; else `acpSessionId ? **C4.
