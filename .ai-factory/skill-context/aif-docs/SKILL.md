### Classify historical vs current before editing
**Source**: 2026-06-27-17.08, 2026-06-23-14.56
**Rule**: Before rewriting any doc hit found by a sweep, classify it: **frozen-historical** (pre-change ADR bodies, dated findings/review docs — they describe the PAST and STAY; rewriting them falsifies history; annotate with a supersession pointer instead) vs **current-contract** (docs stating "what is true now" — these get rewritten). ADR history is immutable — a superseded ADR gets a pointer, never an edit. After ADR-affecting edits, re-run `validate:docs:adr:all` — every new anchor link must resolve.

### Sweep mechanics: both directions, both cases, wrap-tolerant, cited homes
**Source**: 2026-07-02-14.14, 2026-07-01-12.55, 2026-06-27-17.08, 2026-07-04-14.15-brain-review-followup, 2026-06-25-17.42
**Rule**: OpenAPI reconciliation sweeps BOTH directions — phantom params the code never reads (an `hitl_inbox` `limit`/`offset` the handler ignores) AND fields the spec lost but code returns; code wins per docs R3. Column-name greps try BOTH snake_case and the Drizzle camelCase field name (`database-schema.md` documents camelCase — a snake-only grep yields false "missing column" findings). Verify claims with single-line AND whitespace-tolerant patterns (`grep -z` / multi-line) — a load-bearing sentence wrapped across two lines evades a naive grep. When a doc cites another doc as the SSOT home for a topic, update that cited home in the SAME pass — a cross-reference to a doc that never mentions the feature is drift. Patch OpenAPI response-body parity by `operationId`/route block — replacing repeated `$ref`s without route context touches unrelated operations; run `git --no-pager diff -- docs/api/*.yaml` before validation. Attribute changes to migrations only for real DDL — a Drizzle `text({enum})` widening is app-level (no Postgres CHECK → no migration); citing a migration number for it is drift.

### Status flips sweep every surface carrying the tag
**Source**: 2026-06-18-23.21, 2026-06-23-14.56, 2026-06-23-18.25, 2026-06-20-07.30, 2026-07-01-12.55
**Rule**: When a feature ships, grep the feature name AND its ADR number across the whole `docs/` tree INCLUDING `*.openapi.yaml` `summary`/`description` fields, screens docs, and analytics docs for the old `Designed` status word — OpenAPI status tags are the classic straggler (4 stale `ADR-105 — Designed` fork tags; `Designed (inbox card redesign)` left in `web.openapi.yaml`). Superseding a section retires the old prose in the SAME edit — a deleted symbol name left in an "Implemented" section is a self-contradiction; every doc cross-reference must resolve to a file that actually carries the cited value.
